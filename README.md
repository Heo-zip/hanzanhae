# 한잔해

**물을 마시는 작은 습관으로 나만의 정원을 가꾸는 macOS 앱**

일이나 공부에 집중하다 보면 곁에 물을 두고도 마시는 걸 잊기 쉽습니다. 한잔해는 화면 한쪽의 작은 정원을 통해 물 마실 순간을 떠올리게 합니다. 물을 마신 뒤 한 번 눌러 기록하면 식물이 반응하고, 하루 목표를 달성하면 정원이 성장합니다.

> **현재 상태:** 프로젝트 초기 환경 구성 단계입니다. 현재 앱은 기본 화면만 표시하며, 아래 기능은 구현 예정입니다.

## 기획 중인 주요 기능

- **작은 정원** — 화면 한쪽에 정원을 표시하고, 메뉴 막대나 Dock에서 다시 열 수 있습니다.
- **한 잔 기록** — 사용자가 설정한 한 잔의 용량으로 물을 간편하게 기록합니다.
- **목표와 성장** — 하루 목표를 달성하면 식물이 성장하고, 물을 기록할 때 생기를 되찾습니다.
- **로컬 저장** — 로그인 없이 물 기록과 설정을 사용 중인 Mac에 저장합니다.

식물의 시듦 속도와 목표 초과 시 성장량은 실제 사용 경험을 보며 조정할 예정입니다. 씨앗 수집, 정원 사진, 기록 위젯 등은 향후 확장 아이디어입니다.

## 기술 구성

| 영역      | 기술                | 역할                                          |
| --------- | ------------------- | --------------------------------------------- |
| 데스크톱  | Electron            | macOS 앱과 창 관리                            |
| 화면      | React, TypeScript   | 정원 UI와 사용자 입력                         |
| 개발 도구 | electron-vite, Vite | 개발 서버와 빌드                              |
| 데이터    | SQLite              | 목표, 물 기록, 식물 상태의 로컬 저장 **예정** |

MVP는 별도 서버와 계정 없이 동작하도록 설계했습니다. 데이터 동기화는 MVP 범위에 포함하지 않습니다.

## 시작하기

### 요구 사항

- macOS
- Node.js와 npm. 현재 개발 환경은 Node.js 24에서 확인했습니다.

### 설치와 실행

```bash
git clone https://github.com/Heo-zip/hanzanhae.git
cd hanzanhae
npm install
npm run dev
```

### 주요 명령어

```bash
npm run dev        # 개발 모드 실행
npm run lint       # 코드 규칙 검사
npm run typecheck  # TypeScript 타입 검사
npm run build      # 타입 검사 후 앱 코드 빌드
npm run build:mac  # macOS 앱 패키징
```

## 프로젝트 구조

```text
src/
├── main/              # Electron 메인 프로세스: 창과 시스템 기능
├── preload/           # 화면에 필요한 기능을 안전하게 연결하는 통로
└── renderer/          # React 화면
    └── src/
        ├── app/       # 앱 진입 화면
        └── styles/    # 전역 스타일
```

향후 물 기록, 정원, 설정 기능은 `renderer`의 기능별 폴더에 나누고, 데이터 저장과 내부 요청 처리는 Electron 메인 프로세스에서 담당할 예정입니다.
