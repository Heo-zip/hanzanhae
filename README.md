# 한잔해

**물을 마시는 작은 습관으로 나만의 정원을 가꾸는 macOS 앱**

일이나 공부에 집중하다 보면 곁에 물을 두고도 마시는 걸 잊기 쉽습니다. 한잔해는 화면 한쪽의 작은 정원을 통해 물 마실 순간을 떠올리게 합니다. 물을 마신 뒤 한 번 눌러 기록하면 식물이 반응하고, 하루 목표를 달성하면 정원이 성장합니다.

> **현재 상태:** 최초 목표와 한 잔 용량을 설정하고 Mac에 저장·복원할 수 있습니다. 대시보드와 작은 정원 창, 우클릭 숨기기, 전역 단축키, 메뉴 막대를 사용할 수 있습니다. 정원 또는 대시보드에서 물 한 잔을 기록할 수 있습니다. 최근 한 잔과 오늘 현재 목표 기록 전체를 취소할 수 있습니다. 물 기록에 따른 생기와 성장도 임시 기준으로 동작합니다. 통계는 구현 전입니다.

## 기획 중인 주요 기능

- **작은 정원** — 화면 한쪽에 정원을 표시하고, 메뉴 막대나 Dock에서 다시 열 수 있습니다.
- **한 잔 기록** — 사용자가 설정한 한 잔의 용량으로 물을 간편하게 기록합니다.
- **목표와 성장** — 하루 목표를 달성하면 식물이 성장하고, 물을 기록할 때 생기를 되찾습니다.
- **로컬 저장** — 로그인 없이 물 기록과 설정을 사용 중인 Mac에 저장합니다.

식물의 시듦 속도와 목표 초과 시 성장량은 실제 사용 경험을 보며 조정할 예정입니다. 씨앗 수집, 정원 사진, 기록 위젯 등은 향후 확장 아이디어입니다.

## 기술 구성

| 영역      | 기술                | 역할                                    |
| --------- | ------------------- | --------------------------------------- |
| 데스크톱  | Electron            | macOS 앱과 창 관리                      |
| 화면      | React, TypeScript   | 정원 UI와 사용자 입력                   |
| 개발 도구 | electron-vite, Vite | 개발 서버와 빌드                        |
| 데이터    | SQLite              | 목표·용량·물 기록·초기 식물의 로컬 저장 |

MVP는 별도 서버와 계정 없이 동작하도록 설계했습니다. 데이터 동기화는 MVP 범위에 포함하지 않습니다.

## 시작하기

### 요구 사항

- macOS
- Node.js와 npm. 현재 개발 환경은 Node.js 24에서 확인했습니다.

### 설치와 실행

```bash
git clone https://github.com/Heo-zip/hanzanhae.git
cd hanzanhae
npm install
npm run dev
```

### 주요 명령어

```bash
npm run dev        # 개발 모드 실행
npm run lint       # 코드 규칙 검사
npm run test:storage # SQLite 저장·실패·복원 검사
npm run typecheck  # TypeScript 타입 검사
npm run build      # 타입 검사 후 앱 코드 빌드
npm start          # 빌드한 코드를 데스크톱 앱으로 실행 (먼저 npm run build)
npm run build:mac  # macOS 앱 패키징
npm run build:unpack:mac:local # 로컬 검증용 ad-hoc 서명 앱 묶음 생성
```

`npm run dev`는 개발 서버를 띄우고 Electron 데스크톱 앱을 실행합니다. 코드 변경은 개발 모드에서 반영됩니다. 터미널의 `Ctrl + C` 또는 메뉴 막대의 **한잔해 종료**로 종료할 수 있습니다.

정원은 화분을 누르면 물뿌리개가 열리는 미리보기입니다. 화분에서 우클릭해 **정원 숨기기**를 선택하고, **⌘ + ⌥ + ⇧ + H**로 정원을 다시 보이거나 숨길 수 있습니다. 메뉴 막대의 새싹 아이콘과 Dock에서도 다시 열 수 있습니다. 단축키를 다른 앱이 사용 중이면 메뉴 막대에 등록 실패를 표시합니다.

Dock의 확대와 자동 숨김 애니메이션을 따라 움직이는 기능은 아직 실험 전입니다. 현재는 작은 정원을 작업 영역 오른쪽 아래에 놓고 Dock보다 아래의 표시 순서를 사용합니다.

로컬 검증용 앱 묶음은 ad-hoc 서명을 사용하며 배포용 Developer ID 서명·공증을 대신하지 않습니다. macOS arm64 로컬 패키지에서 첫 설정과 재실행 복원을 확인했습니다. 패키지 이름과 서명 확인은 `npm run check:mac:bundle -- "dist/mac-arm64/한잔해.app"`으로 실행합니다. Developer ID 서명·공증과 DMG 설치 검증은 남아 있습니다. 자세한 내용은 [오류 기록](docs/features/initial-setup-packaged-qa-timeout-ERROR.md)을 참고하세요.

## 프로젝트 구조

```text
src/
├── main/              # Electron 메인 프로세스: 창과 시스템 기능
├── preload/           # 화면에 필요한 기능을 안전하게 연결하는 통로
└── renderer/          # React 화면
    └── src/
        ├── app/       # 앱 진입 화면
        ├── features/  # 대시보드와 정원 화면
        └── styles/    # 전역 스타일
```

화면은 `renderer`의 기능별 폴더에 나눕니다. 데이터 저장과 내부 요청 처리는 Electron 메인 프로세스에서 담당할 예정입니다.
