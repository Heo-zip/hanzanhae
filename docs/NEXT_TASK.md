# 다음 작업

> 이 문서는 현재 진행 상태와 바로 이어갈 일을 관리한다. 전체 순서는 [MVP 개발 순서](roadmap.md)를 따른다.

## 현재 작업: 최초 설정과 로컬 저장

- 작업명: [Issue #1 최초 목표 설정과 SQLite 로컬 저장](https://github.com/Heo-zip/hanzanhae/issues/1).
- 상태: 최초 설정·원자적 저장·재실행 복원 구현, 개발 Electron과 저장소 테스트 확인. macOS 패키지 충돌 원인을 수정하고 로컬 ad-hoc arm64 패키지의 최초 설정·재실행 복원을 검증했다. [오류 기록](features/initial-setup-packaged-qa-timeout-ERROR.md)의 배포 서명·공증 및 DMG 확인, 사용자 검증과 커밋·푸시는 남아 있다.
- 기존 변경: 대시보드·정원 미리보기와 `design/` 등 커밋 전 변경이 있다. 새로운 작업 전 변경 범위와 브랜치를 확인한다.

## 현재 기능의 범위와 남은 확인

- [최초 설정 PLAN](features/initial-setup-PLAN.md)을 기준으로 진행한다.
- 목적: 첫 실행에 하루 목표량·한 잔 용량을 설정하고, 앱을 종료해도 목표·설정·초기 식물이 복원되게 한다.
- 구현: Electron 내장 Node `node:sqlite`, 앱 데이터 폴더의 `hanzanhae.sqlite`, 최초 설정 UI와 안전한 IPC를 사용한다. `design/dashboard.html`의 첫 실행과 설정 시안을 반영했다. 목표 중단·재생성, 총량 조정과 한 잔 용량 변경을 구현했다.
- 남은 확인: Developer ID 서명·공증과 DMG 설치, 다른 칩의 패키지 동작은 별도 확인한다. 시안 반영 결과의 사용자 시각 검토가 필요하다.
- 물 한 잔 기록, 성장과 물주기 애니메이션은 다음 기능이다. 저장 API가 없으면 물 기록 UI는 활성화하지 않는다.

## 그다음 작업

1. 한 잔 기록과 두 창의 데이터 갱신, 저장 성공 후 물주기 연출.

3. 생기·성장과 통계 연결. 미정인 수치는 사용하며 결정한다.
4. Dock 위치 반응 실험, 실제 Mac 환경 검증과 패키징은 관련 준비 상태에 따라 진행한다.
