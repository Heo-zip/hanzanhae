# 검증 시나리오

> 아래는 구현할 기능의 검증 기준이다. 현재 자동 테스트 도구와 기능 구현은 아직 없다.

## 변경 후 기본 확인

- 변경 범위에 맞춰 `npm run lint`, `npm run typecheck`, `npm run build`를 실행한다. `build`에는 타입 검사가 포함된다.
- 화면이나 창 동작을 바꾸면 `npm run dev`로 실제 macOS에서 확인한다.
- SQLite나 네이티브 모듈을 추가하면 개발 실행뿐 아니라 macOS 패키징과 재실행도 검증한다.
- 저장·취소처럼 데이터 손실 위험이 있는 동작은 성공뿐 아니라 실패·재시도 경로도 확인한다.

## 최초 설정과 목표

| 시나리오                                     | 기대 결과                                      |
| -------------------------------------------- | ---------------------------------------------- |
| 목표나 한 잔 용량 없이 시작                  | 설정을 건너뛰거나 물을 기록할 수 없음          |
| 목표량·한 잔 용량이 0 이하이거나 정수가 아님 | 저장하지 않고 오류 안내                        |
| 재생성 시 오늘 총량으로 0ml 입력             | 유효한 입력으로 처리                           |
| 재생성 시 오늘 총량이 음수이거나 정수가 아님 | 저장하지 않고 오류 안내                        |
| 최초 설정 중 저장 실패                       | 목표·설정·식물 일부만 남지 않고 다시 시도 가능 |
| 목표 중단                                    | 기록과 성장은 보존, 새 목표 전까지 기록 불가   |
| 500ml 기록 후 새 목표의 총량으로 700ml 입력  | 조정은 +200ml, 총량은 700ml                    |
| 새 목표 작성 중 날짜·총량이 바뀜             | 저장 전 최신 상태 확인 안내                    |

## 물 기록과 취소

| 시나리오                                                          | 기대 결과                                        |
| ----------------------------------------------------------------- | ------------------------------------------------ |
| 목표 1,000ml, 현재 750ml에서 250ml 기록                           | 1,000ml 달성과 성장. 기록은 한 번만 저장         |
| 달성을 만든 마지막 한 잔 취소 후 재기록                           | 750ml와 해당 성장 취소 후 재달성. 성장 중복 없음 |
| 현재 목표에서 오늘 250ml씩 4잔을 기록한 뒤 전체 취소              | 오늘의 네 기록과 관련 성장을 취소, 목표는 유지   |
| 기존 기록 500ml + 조정 200ml + 현재 목표 기록 300ml에서 전체 취소 | 현재 목표와 기존 기록·조정을 유지하고 총량 700ml |
| 전체 취소                                                         | 어제 기록·성장과 오늘 다른 목표 기록·성장 유지   |
| 최근 기록이 바뀐 뒤 이전 기록 취소 요청                           | 오래된 요청을 거절하고 최신 상태 표시            |
| 취소 후 총량이 음수가 되는 조정 조합                              | 취소하지 않고 총량 확인 안내                     |
| 같은 요청 ID와 입력으로 재시도                                    | 물 기록과 성장 중복 없음                         |
| 같은 요청 ID에 다른 입력                                          | 충돌 오류, 추가 저장 없음                        |
| 기록·성장 저장 도중 오류                                          | 둘 다 확정되지 않고 오류 안내                    |

## 시간·복원·창

- 한국 시간 자정 직전 화면에서 자정 이후 기록·취소를 요청하면 날짜 변경을 알리고 최신 상태를 다시 조회한다.
- 날짜가 바뀌면 오늘 총량은 새 날짜 기준이며 목표는 유지된다. UTC 저장 시각과 한국 날짜 경계를 확인한다.
- 정상 종료 및 강제 종료 뒤 재실행할 때 저장된 기록·설정이 복원되고 종료 중 생기 변화가 설계한 방식으로 반영되는지 확인한다. 구체 속도는 미정이다.
- 창을 숨긴 뒤 메뉴 막대와 Dock에서 각각 다시 열 수 있고, 앱 종료 메뉴는 앱을 완전히 종료하는지 확인한다.
- 모니터 연결이 달라져 저장된 창 위치가 화면 밖일 때 보이는 위치로 복구하는지 확인한다.

## 사용자 경험

- 물 기록이 저장된 뒤 물주기와 식물 반응이 보이고, 실패 시 성공 연출이 나타나지 않는지 확인한다.
- 사용자가 전체 취소 전에 취소·유지되는 범위를 이해할 수 있는지 확인한다.
- 작은 정원이 일이나 공부를 방해하지 않으면서 물 마실 순간을 떠올리게 하는지 실제 사용하며 살펴본다.
