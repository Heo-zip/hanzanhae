# 한잔해 문서 안내

이 폴더는 제품·기술 기준과 실제 개발 기록을 관리한다. 구현된 사실과 앞으로 만들 계획은 구분한다.

## 작업을 시작할 때

1. [현재 상태](CONTEXT.md), [다음 작업](NEXT_TASK.md), [결정 기록](DECISION_RECORD.md)을 읽는다.
2. 작업에 필요한 제품·기술 명세와 `design/`의 해당 시안을 확인한다.
3. 새 기능이면 [기능 기획서 템플릿](templates/FEATURE_PLAN_TEMPLATE.md)으로 PLAN을 작성하고 기능 범위와 완료 조건을 확인한다.
4. [작업 흐름](WORKFLOW.md)과 [문서 작성 규칙](DOCUMENTATION_RULES.md)에 따라 진행한다.

## 기준과 충돌 처리

사용자의 최신 명시적 요청을 우선한다. 제품 기획의 원본은 [한잔해 Notion](https://app.notion.com/p/4140b6e5e64c809a9ad6c91dc16def22), UI의 원본은 `design/` HTML과 에셋이다. 기능·저장 규칙은 확정된 기획을 따른다. 접근할 수 없는 원본은 확인했다고 적지 않는다.

제품 기준과 관련된 변경은 명세와 결정 기록을 함께 확인한다. 실제 구현 여부는 코드와 실행 결과를 확인해 CONTEXT에 적는다. PLAN의 제안이나 시안의 임시 데이터는 구현 완료나 확정 정책이 아니다. 문서가 다르면 최신 결정·근거·실제 코드를 확인하고 수정하되, 미확인 사항은 남긴다.
