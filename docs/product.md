# 제품 개요

> 상태: MVP 개발 중. 최초 목표·용량 설정과 SQLite 복원, 대시보드·작은 정원과 창 제어가 있다. 물 기록과 성장 계산은 구현 예정이다.

## 서비스

한잔해는 책상 앞에서 물 마시기를 잊기 쉬운 사람이 작은 정원을 돌보며 물 마실 순간을 떠올리도록 돕는 macOS 앱이다.

**정원을 발견한다 → 물을 마신다 → 한 번 눌러 기록한다 → 식물이 반응한다.**

사용자는 가입 없이 시작하고, 물을 실제로 마신 뒤 기록한다. 목표량과 한 잔 용량은 사용자가 직접 정한다. 기록과 설정은 사용하는 Mac에 보관하며 인터넷 연결 없이 사용하는 것을 목표로 한다.

## 대상과 제품 원칙

- 책상에서 일하거나 공부할 때 물 마시기를 자주 잊는 사람을 대상으로 한다. 이는 사용자 조사 전의 가설이다.
- 기록은 한 번의 조작으로 간단하게 끝낸다.
- 정원은 작업을 방해하지 않는 작은 창으로 제공하고 움직임은 부드럽게 표현한다.
- 정원을 돌보고 싶은 마음이 물을 떠올리는 계기가 되도록 한다. 특정 섭취량을 의학적 권고로 제시하지 않는다.
- 애니메이션과 시각적 피드백을 중시하되 기록 성공 여부는 명확하게 전달한다.

## MVP 범위

| 기능             | 기대 경험                                              |
| ---------------- | ------------------------------------------------------ |
| 최초 설정        | 하루 목표량과 한 잔 용량을 직접 입력하고 시작          |
| 작은 정원        | 항상 위에 표시하는 이동 가능한 창. 고정 여부 변경 가능 |
| 메뉴 막대와 Dock | 숨긴 창을 다시 열고 메뉴에서 앱을 완전히 종료          |
| 물 기록          | 실제로 마신 후 한 잔씩 기록하고 오늘 총량과 목표 확인  |
| 기록 취소        | 최근 한 잔 취소와 오늘 현재 목표 기록 전체 취소 구분   |
| 생기와 성장      | 물 기록 시 생기 회복, 목표 달성과 초과 기록 시 성장    |
| 로컬 보관        | 목표·기록·식물 상태·설정의 저장과 재실행 시 복원       |

대시보드의 최근 7일 그래프·물컵과 달성 통계도 MVP에 포함한다. UI는 [정원 시안](../design/garden.html)과 [대시보드 시안](../design/dashboard.html)을 기준으로 구현한다.

상세 규칙은 [기능 명세](features.md)를 따른다.

## MVP 이후 아이디어

다양한 씨앗과 식물 수집, 키운 정원 모아보기, 정원 사진 저장, 달력·연속 기록 위젯, 기기 간 동기화는 MVP 이후 검토한다. 별도 서버나 계정 도입도 동기화가 필요해질 때 다시 판단한다.

### 물 마시는 동작 감지 실험

- MediaPipe와 카메라로 마시는 듯한 동작을 추정해 기록을 제안하는 선택 기능을 MVP 이후 검토한다. 사용자가 기록 여부와 양을 확인한 뒤에만 저장하며 기존 수동 기록도 유지한다.
- 마신 음료가 물인지, 실제로 얼마나 마셨는지는 카메라만으로 확정할 수 없다. 인식률·오인식·반복 감지, 컵과 자세, 카메라 가림, 배터리·성능을 먼저 실험한다.
- 기본 꺼짐과 사용자 권한을 전제로 하며, 영상은 Mac에서만 처리하고 저장·전송하지 않는 방향을 제안한다. 표시 위치는 정원에 숫자나 말풍선을 띄우지 않는 원칙을 고려해 정한다.
- 확인 화면과 기록량 입력 방식, 인식 기준 및 실제 도입 여부는 실험 후 결정한다.

## 확인할 가설과 미정 사항

- 정원을 보고 물을 마실 순간을 떠올리는가?
- 기록이 충분히 간단하고 창이 업무를 방해하지 않는가?
- 식물의 시각 디자인은 `design` 시안을 기준으로 한다. 시듦 속도와 최종 모습, 목표 초과 성장량은 사용하면서 정한다.
- 새 목표를 만드는 시점에 오늘 총량이 이미 목표 이상일 때 성장 보상은 미정이다.
