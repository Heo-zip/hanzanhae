# 제품 개요

> 상태: MVP 개발 중. 최초 목표·용량 설정과 SQLite 복원, 대시보드·작은 정원과 창 제어가 있다. 물 기록·성장·최근 7일 통계를 구현했다.

## 서비스

한잔해는 책상 앞에서 물 마시기를 잊기 쉬운 사람이 작은 정원을 돌보며 물 마실 순간을 떠올리도록 돕는 macOS 앱이다.

**정원을 발견한다 → 물을 마신다 → 횟수를 기록한다 → 텀블러를 비우면 물을 주고 식물이 자란다.**

사용자는 가입 없이 시작하고, 물을 실제로 마신 뒤 기록한다. 하루 목표 횟수와 텀블러 용량은 사용자가 직접 정한다. 기록과 설정은 사용하는 Mac에 보관하며 인터넷 연결 없이 사용하는 것을 목표로 한다.

## 대상과 제품 원칙

- 책상에서 일하거나 공부할 때 물 마시기를 자주 잊는 사람을 대상으로 한다. 이는 사용자 조사 전의 가설이다.
- 기록은 한 번의 조작으로 간단하게 끝낸다.
- 정원은 작업을 방해하지 않는 작은 창으로 제공하고 움직임은 부드럽게 표현한다.
- 정원을 돌보고 싶은 마음이 물을 떠올리는 계기가 되도록 한다. 특정 섭취량을 의학적 권고로 제시하지 않는다.
- 애니메이션과 시각적 피드백을 중시하되 기록 성공 여부는 명확하게 전달한다.

## MVP 범위

| 기능             | 기대 경험                                              |
| ---------------- | ------------------------------------------------------ |
| 최초 설정        | 하루 목표 횟수와 텀블러 용량을 직접 입력하고 시작          |
| 작은 정원        | 항상 위에 표시하는 이동 가능한 창. 고정 여부 변경 가능 |
| 메뉴 막대와 Dock | 숨긴 창을 다시 열고 메뉴에서 앱을 완전히 종료          |
| 물 기록          | 마신 횟수와 비운 텀블러의 용량을 각각 기록  |
| 기록 취소        | 최근 횟수 취소와 텀블러 기록 취소를 구분   |
| 생기와 성장      | 마신 횟수·텀블러 기록 시 생기 회복과 성장(횟수 1회 100점, 용량 1ml 1점) |
| 로컬 보관        | 목표·기록·식물 상태·설정의 저장과 재실행 시 복원       |

대시보드의 최근 7일 그래프·물컵과 달성 통계도 MVP에 포함한다. UI는 로컬 `design/garden.html`과 `design/dashboard.html`을 기준으로 구현한다.

상세 규칙은 [기능 명세](features.md)를 따른다.

### 생기 기준

| 항목 | 값 |
| --- | --- |
| 사용 중 | 시간당 -10 |
| 화면 잠금·잠자기·앱 종료 | 시간당 -2 |
| 마신 횟수 (카메라 감지) | +6, 제한 없음 |
| 마신 횟수 (버튼) | +6, 5분에 한 번 |
| 텀블러 비움 | +15, 카메라 감지를 끈 상태면 +30 |
| 범위와 시작 | 20~100, 새 사용자 60 |

한 시간에 두 번 마시면 생기가 조금씩 오르고, 세 시간에 다섯 번 마시면 유지된다. 기록을 취소하면 그 기록이 올린 만큼 되돌린다. 식물 사진은 생기 100·80·60·40·20의 5단계로 보여 준다. 수치는 사용하며 조정한다.

## MVP 이후 아이디어

다양한 씨앗과 식물 수집, 키운 정원 모아보기, 정원 사진 저장, 달력·연속 기록 위젯, 기기 간 동기화는 MVP 이후 검토한다. 별도 서버나 계정 도입도 동기화가 필요해질 때 다시 판단한다.

### 식물이 보내는 물 마시기 알림

- 마신 횟수 기록이 오래 없으면 식물이 말을 거는 macOS 시스템 알림을 요청한다. 생기에 따라 문구가 달라지고 알림을 눌러도 물을 자동 기록하지 않는다.
- 설정의 기본은 꺼짐·2시간 간격·한국 시간 09:00~21:00이며 사용자가 조절할 수 있다. 활성 목표가 없거나 목표를 채우면 알리지 않는다. 수치는 실제 사용하며 조정한다.
- 앱 실행 중에만 동작한다. 완전히 종료된 상태의 알림은 별도 실행 구조가 필요하므로 범위 밖이다.
- Electron 시스템 알림 요청과 실패 안내를 연결했고 사용자가 알림 표시와 클릭 후 대시보드 열기를 확인했다. 간격 경과 후 자동 알림은 별도 확인한다. [오류 기록](features/plant-reminders-macos-permission-ERROR.md)과 [노션 기획](https://app.notion.com/p/4180b6e5e64c8127b1d6e37370848bb7)을 따른다.

### 물 마시는 동작 감지

- 첫 배포에서 안내할 카메라 감지 범위는 텀블러로 직접 마시기와 빨대 음용이다. 지원 범위는 실제 기기 검증을 거쳐 넓힌다.
- 사용자가 설정에서 카메라를 켜면 MediaPipe로 컵·병을 든 채 고개를 젖히거나 빨대로 마시는 동작을 감지해 마신 횟수를 자동 기록한다. 연속된 여러 모금은 한 번으로 묶고, 대시보드 알림과 정원에서 15초 안에 되돌릴 수 있다.
- 카메라만으로 음료 종류나 실제 섭취량을 확정할 수 없다. 자동 감지는 횟수만 기록하고(횟수도 성장점을 더한다) 물의 양은 사용자가 텀블러를 비웠을 때 별도로 기록한다.
- 카메라 사용은 선택 사항이다. 영상은 기기 안에서 처리하고 저장·전송하지 않는다. 실제 오감지·놓침 비율과 배터리·다른 화상회의 앱과의 충돌은 사용하며 확인한다. 세부 기준은 [카메라 감지 TECH](features/camera-drink-detection-TECH.md)를 따른다.

## 확인할 가설과 미정 사항

- 정원을 보고 물을 마실 순간을 떠올리는가?
- 기록이 충분히 간단하고 창이 업무를 방해하지 않는가?
- 식물의 시각 디자인은 `design` 시안을 기준으로 한다. 시듦 속도와 최종 모습, 목표 초과 성장량은 사용하면서 정한다.
- 텀블러 용량에 비례하는 성장 수치와 카메라 감지 판정 간격은 사용·실험하며 조정한다.
