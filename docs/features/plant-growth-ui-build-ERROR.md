# 성장 화면 타입 검사 오류

- 발생: 2026-11-13 / 상태: 해결 / 관련 기능: [식물 생기와 성장](plant-growth-PLAN.md)

## 현상과 원인

대시보드 이미지 목록을 공통 식물 목록으로 바꾸는 중 기존 `stage3` 참조가 남아 타입 검사가 실패했다. 물주기 연출 상태를 만든 뒤 이미지 JSX에 연결하지 않은 상태에서도 사용하지 않는 변수 오류가 발생했다. 새 JavaScript 테스트의 보조 함수 두 개는 타입 검사 린트 규칙과 충돌했다.

## 해결과 검증

이미지 참조를 공통 목록으로 교체하고 물주기 연출 상태를 이미지에 연결했다. JavaScript 테스트 보조 함수에는 해당 규칙만 예외 처리했다. 타입 검사·린트·빌드가 통과했다.
