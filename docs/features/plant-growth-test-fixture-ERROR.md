# 성장 스키마 이전 테스트 모형 오류

- 발생: 2026-11-13 / 상태: 해결 / 관련 기능: [식물 생기와 성장](plant-growth-PLAN.md)

## 현상과 원인

스키마 5에서 기존 저장소 테스트가 새 상태 필드 누락과 `table growth_events already exists`로 실패했다. 테스트가 이전 버전 DB를 만들 때 버전 번호만 낮추고 버전 5 테이블은 남겨 실제 과거 DB와 다른 모형을 만들었다. 기존 상태 비교에도 생기와 성장점 필드가 빠졌다.

## 해결과 검증

과거 버전 모형에서 해당 버전보다 나중에 생긴 테이블을 제거하고, 초기 생기와 성장점을 예상값에 포함했다. 기존 기록을 소급 성장하지 않는 버전 4 이전 사례도 추가했다. 저장소 테스트 25개가 통과했다.
