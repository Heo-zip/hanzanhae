# 한 잔 용량 화면 검증 시간 초과

- 기능: 설정 시안 반영 / 발생일: 2026-11-13 / 상태: 해결 / 심각도: 낮음
- 환경: macOS 개발 Electron, 별도 임시 데이터.

설정 화면 자동 검증이 한 잔 용량 변경 후 저장값을 기다리다 시간 초과됐다. 검증 스크립트가 텍스트 입력 직후 입력 완료를 기다리지 않고 포커스를 해제한 것이 원인이었다. 실제 키 입력 반영을 기다린 뒤 포커스를 해제하도록 테스트 순서를 수정했다.

같은 흐름을 새 임시 데이터로 다시 실행해 한 잔 용량 저장과 앱 재실행 후 복원을 확인했다. 패키지 앱 충돌과는 별개의 테스트 스크립트 문제다.
