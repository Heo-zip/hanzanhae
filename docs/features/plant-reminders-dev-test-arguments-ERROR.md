# 개발 앱 격리 검증 인자 누락

## 현상

격리 데이터로 `npm run dev`를 검증하려고 `ELECTRON_CLI_ARGS` 환경 변수에 사용자 데이터 경로를 전달했지만, 실행 중인 기존 앱으로 연결되며 새 테스트 경로가 만들어지지 않았다.

## 원인과 해결

`electron-vite` CLI가 환경 변수의 값을 CLI 인자 목록으로 덮어썼다. `npm run dev -- -- --user-data-dir=/private/tmp/hanzanhae-issue25-fresh`처럼 `--` 뒤에 Electron 인자를 넘기자 별도 데이터 경로로 실행됐다. 실제 테스트 기록을 새 경로에 생성하고 저장·재실행 복원을 확인했다. 사용자 데이터 자체는 바꾸지 않았다.

## 예방

격리 테스트에서는 앱이 표시되기 전에 실제 사용자 데이터 경로와 별도 프로세스인지 확인한다. 기존 앱이 실행 중이면 단일 인스턴스가 기존 앱을 열 수 있다.
