# 물 기록 취소 결과

- 날짜: 2026-11-13 / 이슈: [#5](https://github.com/Heo-zip/hanzanhae/issues/5) / 브랜치: `feature/water-record-cancel`
- 계획: [물 기록 취소 PLAN](water-cancel-PLAN.md)

## 구현

- 대시보드의 최근 한 잔 취소와 전체 취소, 물주기 후 정원에 잠시 나타나는 되돌리기를 연결했다.
- `design/dashboard.html`의 전체 취소 모달을 적용했다. 현재 목표의 오늘 대상 잔 수·양, 취소 전후 총량과 유지할 목표·다른 기록·직접 입력한 양을 안내한다. 음수가 되면 취소를 막고 설정으로 안내한다.
- 확인창을 열 때 취소 대상을 고정해 다른 창에서 기록이 추가되면 오래된 요청을 거절한다.
- DB 버전 4에서 취소 시각과 요청 결과를 함께 저장한다. 현재 목표·한국 날짜·최신 기록 또는 확인한 전체 대상이 달라지거나 취소 후 총량이 음수면 저장하지 않는다.
- 같은 요청의 재전송을 중복 적용하지 않는다. 저장 실패와 결과 미확인 시 같은 요청 ID로 재시도하며, 정원에서는 전체 취소 API를 호출할 수 없다.
- 이 보고서 작성 당시 성장·생기는 미구현이었다. 이후 [생기·성장 계획](plant-growth-PLAN.md)에서 기록과 함께 연결했다.

## 검증

- `npm run test:storage`: 18개 통과. 최신·전체 범위, 이전 목표·다른 날짜·조정 보존, 음수 차단, 중복 요청, 저장 실패 롤백, 자정, 목표 변경, 버전 1·2·3 이전과 재실행을 확인했다.
- 별도 임시 데이터의 macOS 개발 Electron: 최근·전체 취소, 확인창 취소, 500ml 이전 기록과 200ml 조정 보존, 정원 되돌리기, 음수 총량 차단 안내, 강제 실패·재시도, 정원의 전체 취소 차단 및 재실행을 확인했다.
- 별도 임시 데이터의 macOS arm64 ad-hoc 패키지: 정원 최근 취소·수정한 대시보드 모달의 전체 취소·재실행과 패키지 서명·이름 검사를 통과했다.
- 사용자가 기존 취소 흐름의 QA를 통과했다. 이후 수정한 모달은 같은 창 크기의 시안 비교와 별도 임시 데이터 Electron 검사로 확인했다. 확인창 유지·닫기, 기록 변경 시 차단, 저장 실패·재시도와 음수 차단을 검증했다. 수정한 모달의 사용자 직접 QA는 별도로 진행하지 않았다.
- 타입 검사·린트·빌드 통과. [이전 테스트 모형 오류](water-cancel-test-migration-ERROR.md)는 해결했다.
