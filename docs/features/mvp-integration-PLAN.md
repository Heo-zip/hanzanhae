# MVP 통합 검증 계획

- 이슈: [#27](https://github.com/Heo-zip/hanzanhae/issues/27)
- 상태: 완료, 일부 환경 검증 별도 / 2026-11-14

## 목적과 범위

개별 기능이 연결된 흐름에서도 사용자 기록과 화면 상태가 일치하는지 확인한다. 최초 설정, 물 기록, 목표 달성·성장, 최근·전체 취소, 통계와 재실행 복원을 대상으로 한다. 실제 데이터가 아닌 임시 데이터로 검증한다.

## 검증 흐름

1. 초기 상태에서 하루 목표와 한 잔 용량을 설정한다.
2. 물을 기록해 목표를 달성하고 화면의 합계·성장·통계를 확인한다.
3. 최근 기록을 취소하고 합계·성장·통계·알림의 마지막 유효 기록 기준이 함께 갱신되는지 확인한다.
4. 재기록과 오늘 전체 취소 후 목표는 유지되고 오늘의 물과 관련 성장이 되돌아가는지 확인한다.
5. 종료 후 재실행해 목표와 기록·설정이 복원되는지 확인한다.
6. 별도 시스템 환경이 필요한 정원 커서, macOS 배너와 자동 알림은 결과에 확인 여부를 구분한다.
