# 취소 스키마 추가 후 과거 버전 이전 테스트 실패

- 발생일: 2026-11-13 / 상태: 해결 / 관련: [취소 PLAN](water-cancel-PLAN.md)

취소 요청 이력 테이블 `cancel_receipts`를 버전 4에 추가한 뒤, 과거 버전 모형을 만드는 기존 테스트 두 개가 `table cancel_receipts already exists`로 실패했다. 테스트가 최신 DB에서 버전 번호를 낮추면서 새 테이블은 제거하지 않아, 과거 버전 DB를 정확히 모형화하지 못한 것이 원인이었다.

테스트 모형에서 해당 테이블을 제거하도록 수정하고 실제 버전 3 기록을 보존하는 이전 테스트를 추가했다. 이후 버전 1·2·3 이전을 포함한 저장소 테스트 18개가 통과했다. 사용자 DB를 변경하거나 초기화한 오류는 아니었다.
