# 최초 설정과 설정 화면 반영 결과

- 날짜: 2026-11-13 / 계획: [PLAN](setup-settings-design-PLAN.md) / 브랜치: `feature/dashboard-ui`
- 기준: `design/dashboard.html`, 최초 설정과 목표 변경에 관한 기존 제품 명세.

## 구현

- 대시보드 창의 환영·목표 입력·한 잔 입력·확인 화면과 시안의 화분·배경·전환 효과를 구현했다. 설정 전에는 입력을 건너뛸 수 없다.
- 설정에서 목표 중단·새 목표 시작, 오늘 총량 조정, 한 잔 용량 변경을 지원한다. 목표 교체 시 이전 목표와 식물을 보존하고 조정 차이만 원자적으로 저장한다.
- DB 버전 1을 버전 2로 이전하며 `daily_adjustments`와 `settings_receipts`를 추가한다. 화면과 저장 시점의 목표·한국 날짜·총량이 다르면 저장하지 않고 다시 확인하도록 한다.
- 원시 IPC를 노출하지 않고 대시보드에만 설정 변경을 허용한다. 정원에는 상태 변경만 알린다. 시안의 가짜 창 제어 점을 삭제하고 실제 macOS 창 제어는 유지한다.

## 검증

- `npm run test:storage`: 최초 설정, 입력 검증, 중복 요청, 목표 이력과 조정, 중단·재생성, 오류 롤백, 버전 1 이전과 재실행 등 7개 통과.
- 임시 저장소를 쓰는 개발 Electron: 최초 설정 빈 입력 차단, 목표·용량 저장, 두 창 갱신, 목표 변경과 총량 조정, 한 잔 용량 변경, 정원 창의 쓰기 차단, 재실행 복원, 목표 중단 후 화분 유지와 새 목표 생성 확인.
- 동일 크기 시안과 개발 앱의 환영·목표 변경 화면을 비교하고 컵 크기와 목표 글자 크기를 조정했다. 시안의 데모 수치와 가짜 창 제어 버튼은 실제 화면에 넣지 않았다.
- `npm run lint`와 `npm run build`(타입 검사 포함) 통과. 이후 패키지 실행 충돌의 원인을 수정하고 로컬 arm64 패키지의 첫 설정·복원을 확인했다. [오류 기록](initial-setup-packaged-qa-timeout-ERROR.md)을 참고한다.

## 한계와 후속

- 실제 물 기록·성장·취소는 아직 없다. 현재 오늘 총량은 조정만 포함하며, 물 기록 기능을 구현할 때 유효 기록 합을 더해야 한다.
- Dock 위치 옵션, 위젯 설정과 자동 실행 설정은 아직 비활성화 상태다. 패키지·DMG 실행과 배포는 확인하지 않았다.
- [CSS 오류](setup-settings-design-css-ERROR.md)와 [테스트 시간 초과](setup-settings-design-test-timing-ERROR.md), [테스트 반환값 오류](setup-settings-design-test-clone-ERROR.md)는 해결했다.
