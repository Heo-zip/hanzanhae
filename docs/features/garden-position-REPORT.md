# 정원 위치와 창 설정 결과

- 이슈: [#15](https://github.com/Heo-zip/hanzanhae/issues/15) / 계획: [정원 위치 PLAN](garden-position-PLAN.md)

## 구현

- 화분을 눌렀을 때는 물뿌리개가 열리고, 5px 이상 끌면 창이 이동한다. 이동 후 물주기 버튼은 그대로 사용할 수 있다.
- 설정에서 Dock 위·화면 바닥 프리셋과 다른 창 위에 표시 여부를 선택할 수 있다. 직접 이동하면 두 프리셋의 선택 강조가 해제된다.
- 좌표·프리셋/직접 위치·항상 위 여부를 SQLite에 저장하고 재실행 시 복원한다. 스키마 6은 기본 설정, 7은 직접 이동 상태를 지원하며 기존 목표·기록을 유지한다.
- 화면과 겹치지 않는 위치는 기본 화면으로 복구하고 일부만 벗어난 위치는 화면 안으로 보정한다. 화면 변경 중 숨긴 창은 자동으로 보이지 않는다.
- 드래그가 취소되거나 창이 숨겨지면 저장 전 위치로 돌아간다. 저장 오류 시 실제 창도 이전 상태로 되돌리고 오류를 안내한다.
- 전체 화면에서 화분이 보이지 않는 제보에 따라 macOS 정원 창을 패널로 변경했다. 사용자가 수정 후 문제가 없다고 확인했다. [오류 기록](garden-position-fullscreen-ERROR.md)

## 검증

- 저장소 테스트 31개와 화면 배치 테스트 3개 통과. 초기 설정 전 저장·재실행, 스키마 1~6 이전, 실패·잘못된 입력, 음수 좌표·화면 제거·Dock/바닥 기준을 확인했다.
- 실제 Electron에서 테스트 입력으로 클릭·드래그·물주기, 직접 이동 시 선택 해제, 저장 실패·포인터 취소·숨기기 복구, 프리셋·항상 위 설정, 화면 이탈 보정과 재실행을 확인했다. 설정 화면을 시안과 비교했다.
- 임시 데이터의 macOS arm64 로컬 ad-hoc 패키지에서 위치·항상 위 설정 저장, 물 기록·취소와 재실행 및 패키지 서명·이름 검사를 확인했다.
- 타입 검사·린트·빌드 통과. [위치 복원 오류](garden-position-restore-ERROR.md), [검증 입력 오류](garden-position-test-input-ERROR.md), [린트 오류](garden-position-lint-ERROR.md)를 해결했다.
- 패널 변경 후 임시 데이터의 Electron에서 Dock 표시 상태, 모든 작업 공간 설정, 항상 위 켜기·끄기와 화분 클릭을 확인했다. 이는 전체 화면 위에 실제로 보이는지 확인한 결과는 아니다.
- 사용자가 수정 후 직접 확인하고 문제가 없다고 응답했다.

## 남은 확인

- 물리 마우스 사용감과 실제 여러 대의 모니터 연결·해제는 사용자 환경에서 확인한다. 다중 화면 배치는 가상 좌표 테스트로 검증했다.
- Dock 확대 시 화분과의 순서가 유지되는지 확인한다.
- Dock의 자동 숨김·확대 애니메이션 실시간 추적과 로그인 자동 실행은 범위 밖이다. Developer ID 서명·공증과 DMG 설치는 미검증이다.
