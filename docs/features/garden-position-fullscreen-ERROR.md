# macOS 전체 화면에서 정원이 보이지 않는 현상

- 상태: 해결, 사용자 전체 화면 확인 / 관련 기능: [정원 위치 계획](garden-position-PLAN.md)

## 현상과 원인 후보

사용자 환경에서 다른 앱을 전체 화면으로 사용할 때 화분이 보이지 않았다. 항상 위 설정은 켜져 있었다. 기존 일반 창은 모든 작업 공간과 전체 화면 표시를 요청했지만 실제 화면에 겹쳐 나타나는지 확인되지 않았다. macOS의 작업 공간과 창 종류가 관련될 가능성이 있으며 정확한 원인은 아직 확정하지 않았다.

## 변경과 검증

정원에 macOS 전용 `panel` 창 유형을 적용하고 전체 화면 작업 공간에 표시하도록 설정했다. 앱의 Dock 아이콘을 유지하도록 작업 공간 설정 시 프로세스 유형 변환은 생략한다. 항상 위 순서는 Dock 아래인 `floating`을 유지한다.

임시 데이터로 실제 Electron 앱을 실행해 두 창 생성, Dock 아이콘 표시 상태, 모든 작업 공간 설정, 항상 위 설정 변경과 화분 클릭을 확인했다. 타입 검사·린트·빌드와 저장소·위치 테스트가 통과했다. 격리된 전체 화면 테스트 앱의 캡처만으로는 겹쳐 보이는 화면을 확인하지 못했으나, 이후 사용자가 자신의 환경에서 수정 후 문제가 없다고 확인했다. Dock 확대·자동 숨김과 여러 모니터 환경의 동작은 별도 검증 범위다.
