# 식물 상태 기반 물 마시기 알림 결과

> 구현과 검증 결과다. 격리된 Electron 앱의 macOS 알림 표시와 클릭 후 대시보드 열기를 사용자가 확인했다.

- [Issue #18](https://github.com/Heo-zip/hanzanhae/issues/18) · [PLAN](plant-reminders-PLAN.md) · [노션 기획](https://app.notion.com/p/4180b6e5e64c8127b1d6e37370848bb7)

## 구현

- 설정에서 알림을 켜고 끄며 간격과 한국 시간 기준 시작·종료 시각을 고른다. 기본은 꺼짐·2시간·09:00~21:00이다. 테스트 알림은 발송 간격에 영향을 주지 않는다.
- 꺼진 알림을 켜고 저장하면 즉시 확인 알림을 요청한다. macOS가 거부하면 설정은 저장하되 화면에 알리고, 표시 성공 시에는 해당 시각부터 중복 발송 간격을 센다.
- 활성 목표가 있고 오늘 목표 미달일 때, 목표 시작 또는 마지막 유효 물 기록과 마지막 알림 후 정한 시간이 지나면 알림을 요청한다. 생기 45 미만과 그 외의 문구를 구분한다.
- Main이 1분마다 조건을 확인하며 잠자기 복귀 시에도 확인한다. 표시 이벤트를 받으면 시각을 저장해 재시작 후 중복 발송을 제한한다. 표시 실패는 성공으로 저장하지 않으며 실패한 요청은 짧은 간격으로 반복하지 않는다.
- 알림 클릭은 대시보드를 연다. 알림으로 물을 자동 기록하지 않으며 앱이 완전히 종료된 동안에는 알림을 보내지 않는다.
- SQLite 스키마 버전 8에서 알림 설정과 마지막 발송 시각을 저장한다. 기존 목표·물 기록·정원 설정은 보존한다.

## 검증

- 저장소 33개, 위치 3개, 알림 정책·서비스 11개 테스트와 타입 검사·린트·빌드가 통과했다. 알림 성공·실패와 클릭의 서비스 테스트는 Electron 모의 객체를 사용했으며 실제 macOS 표시 검증이 아니다.
- 임시 데이터의 실제 Electron에서 설정 화면 표시, 기본 꺼짐, 저장, 잘못된 입력과 다른 창의 IPC 호출 차단을 확인했다. 설정 화면을 캡처해 기존 스타일과 비교했다.
- 기존 사용자 데이터를 쓰지 않는 macOS arm64 ad-hoc 패키지를 생성하고 패키지 이름·보조 앱·서명 검사를 통과했다.
- `/private/tmp`의 격리된 개발 앱과 테스트 패키지는 macOS가 알림을 거부했다. 이후 작업 폴더의 독립 네이티브 앱에서 사용자가 권한을 허용했고, 별도 데이터의 Electron 테스트 패키지에서 `show` 이벤트가 발생했다. 사용자는 별도로 실행한 테스트 앱의 실제 알림 표시와 클릭 후 대시보드 열기를 확인했다. [알림 표시 오류](plant-reminders-macos-permission-ERROR.md)를 참고한다.
- [테스트 모듈 오류](plant-reminders-test-import-ERROR.md)와 [테스트 린트 오류](plant-reminders-test-lint-ERROR.md)는 수정했다. 원인과 재검증을 해당 문서에 남겼다.

## 남은 확인

- 알림 배너의 실제 화면 표시와 클릭은 사용자가 확인했다. 정해진 간격 경과 후 자동 알림, 집중 모드, 권한 거부 및 다른 환경의 앱 등록 동작은 별도로 확인한다.
- 알림 간격 선택창의 테두리·펼친 목록과 설정 UI는 [후속 Issue #19](https://github.com/Heo-zip/hanzanhae/issues/19)에서 개선한다. 키보드 포커스와 접근성은 유지한다.
- Developer ID 서명·공증, DMG 설치, 실제 장시간 사용과 다른 Mac 칩은 미검증이다. 간격·시간대·문구와 생기 기준은 사용하며 조정한다.

## 유지보수

- 설정과 표시 시각은 물 기록과 별도다. 알림 실패가 물 기록을 막거나 기존 기록을 변경하면 안 된다.
- 테스트 알림과 자동 알림을 구분한다. 실제 표시 전에는 성공 시각을 남기지 않고, 표시 후 저장 실패 시 중복 대신 저장 재시도를 우선한다.
- 시스템 알림은 운영체제 권한과 Electron의 플랫폼 동작에 영향을 받는다. 단위 테스트의 모의 성공과 실제 Mac 화면의 표시 성공을 구분한다.
