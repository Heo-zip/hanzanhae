# 물 기록 상태 확장 후 기존 테스트 실패

- 발생일: 2026-11-13 / 상태: 해결 / 관련: [물 기록 PLAN](water-record-PLAN.md)

물 기록 구현으로 앱 상태에 `todayRecords`가 추가되면서 기존 테스트의 전체 객체 비교가 실패했다. 기존 스키마 이전 테스트는 새 `water_records` 테이블을 제거하지 않은 채 버전 1로 되돌린 테스트 DB를 만들어 테이블 중복 오류가 발생했다.

실제 데이터 손상은 아니며 테스트의 기대값과 과거 DB 모형이 이전 스키마를 정확하게 표현하지 못한 문제였다. 빈 기록 목록을 기대값에 추가하고 과거 버전 모형에서 새 테이블을 제거했다. 버전 1·2 이전, 실제 물 기록·중복·실패·자정 경계 테스트도 추가해 11개 통과를 확인했다.
