# 물 섭취 통계 결과

- 이슈: [#13](https://github.com/Heo-zip/hanzanhae/issues/13) / 계획: [물 섭취 통계 PLAN](water-statistics-PLAN.md)

## 구현

- 한국 시간 기준 최근 7일 섭취량과 그날 마지막 목표를 시안의 그래프와 물컵에 표시한다. 목표선은 각 날짜의 목표를 따르며, 목표가 없던 날짜에는 목표선을 표시하지 않는다.
- 최근 7일 중 목표가 있던 날의 평균과 달성 횟수, 최다 섭취일을 표시한다. 기록이 0이면 최다일은 표시하지 않고 동률이면 가장 최근 날짜를 선택한다.
- 연속 달성은 7일 밖 이력까지 계산한다. 오늘이 미달성이면 어제부터 세고, 과거 미달성 또는 목표 없는 날에 끊는다. 목표를 중단한 당일에는 마지막 목표를 적용하고 다음 날부터는 목표 없음이다.
- 목표 시작·중단 이력, 취소되지 않은 물 기록과 총량 조정을 읽기 트랜잭션에서 재계산한다. 기존 DB 스키마와 데이터를 변경하지 않는다. 기록·취소·목표 변경 시 갱신하며 조회 실패 시 재시도할 수 있다.
- 차트는 마우스와 키보드로 날짜별 설명을 확인할 수 있다. 통계 조회 IPC는 대시보드 메인 프레임에만 허용한다.

## 검증

- 저장소 테스트 28개 통과: 한국 자정, 목표 변경·중단·재생성, 조정과 취소, 목표 없는 날, 7일 초과 연속 달성 및 재실행을 확인했다.
- 실제 Electron에서 시안과 같은 데이터·창 크기로 그래프와 물컵을 비교했다. 1280×800과 1024×700에서 일곱 날짜의 툴팁 위치를 확인하고, 기록·취소·목표 변경·조회 오류와 재시도 및 정원의 통계 접근 차단을 검증했다.
- 임시 데이터의 macOS arm64 ad-hoc 패키지에서 물 기록·차트·취소·재실행 및 패키지 이름·서명 검사를 통과했다.
- 타입 검사·린트·빌드를 통과했다. [린트 오류](water-statistics-lint-ERROR.md)와 [툴팁 오류](water-statistics-tooltip-ERROR.md)는 해결했다.

## 남은 확인

- 실제 사용 데이터와 사용자의 직접 QA를 확인한다. Developer ID 서명·공증, DMG 설치와 다른 Mac 칩은 검증하지 않았다.
