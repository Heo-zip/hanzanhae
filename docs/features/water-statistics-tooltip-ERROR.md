# 차트 툴팁이 창 밖으로 넘치는 문제

- 상태: 해결 / 관련 기능: [물 섭취 통계](water-statistics-PLAN.md)

## 현상과 원인

오른쪽 막대의 긴 툴팁이 차트 바깥으로 넘치면서 대시보드에 가로 스크롤이 생겼다. 막대 중심을 기준으로 툴팁을 배치해 양 끝에서 충분한 공간을 확보하지 못한 것이 원인이다.

## 해결과 검증

양 끝의 툴팁은 차트의 좌우 경계에 맞추고 너비를 차트 안으로 제한했다. 실제 Electron에서 기본·최소 창 크기의 일곱 막대를 키보드로 순회하며 툴팁이 차트 안에 남는지 확인했다.
