# 최초 설정 화면의 초기 상태 조회 린트 오류

## 기본 정보

- 기능: 최초 설정과 로컬 저장 / Issue #1
- 발생일: 2026-11-13 / 상태: 해결
- 환경: React 19, 프로젝트 ESLint 설정, macOS 개발 환경

## 재현과 결과

1. 시작 상태 조회 함수에서 IPC를 호출하고 React 상태를 갱신하도록 구현한다.
2. `useEffect` 본문에서 조회 함수를 즉시 호출한다.
3. `npm run lint`에서 `react-hooks/set-state-in-effect` 오류가 발생한다.

기대 결과는 초기 상태를 비동기로 조회하면서 린트 규칙을 통과하는 것이다. 실제로는 초기 조회 함수가 effect에서 동기적인 상태 변경으로 인식되었다.

## 원인과 해결

- 원인: effect가 상태를 갱신하는 함수를 직접 호출해 연쇄 렌더링을 방지하는 규칙이 적용됐다.
- 해결: 최초 조회를 Promise 콜백에서 시작하고, 저장 상태 변경 알림도 구독 콜백에서 다시 조회한다.
- 변경 파일: `src/renderer/src/app/App.tsx`.

## 확인

- 수정 후 린트·빌드와 실제 Electron의 최초 조회·설정 뒤 정원 갱신을 확인했다.
