# 정원 클릭 커서가 표시되지 않는 현상

- 관련 이슈: [#20](https://github.com/Heo-zip/hanzanhae/issues/20)
- 상태: 대응 코드 적용, 실제 macOS 마우스 확인 필요

## 현상과 확인한 내용

사용자가 화분에 마우스를 올려도 클릭할 수 있는 커서가 표시되지 않는다고 제보했다. 화분에는 이미 `cursor: pointer`가 설정되어 있었다. 정원은 투명한 영역을 클릭 통과시키다가 화분 위에서는 통과를 해제하는 창이므로, 커서 갱신 시점이 영향을 줄 가능성이 있다. 이것이 원인이라고 확정하지는 않았다.

## 대응

클릭 통과가 해제된 뒤 메인 프로세스가 렌더러에 알리고, 렌더러가 커서 스타일을 다시 계산한다. 물뿌리개에도 클릭 커서를 지정하고, 화분에 마우스를 올리면 은은한 그림자로 상호작용을 안내한다. 기존 클릭 통과와 드래그 경로는 유지한다.

## 검증과 남은 확인

타입 검사·빌드·린트와 정원 위치 자동 테스트 3개를 통과했다. 실제 macOS에서 다른 앱 위의 화분과 물뿌리개에 마우스를 올려 커서가 바뀌는지, 빈 공간 클릭 통과·클릭·드래그·숨기기와 복귀를 확인해야 한다. 실제 커서가 바뀌는지는 아직 확인하지 못했다.
