# 물 마시기 횟수 목표와 텀블러 기록 계획

- 관련 이슈: [#34](https://github.com/Heo-zip/hanzanhae/issues/34)
- 기획: [한잔해](https://app.notion.com/p/4140b6e5e64c809a9ad6c91dc16def22)
- 상태: 구현·자동 검증 완료. 카메라와 자동 감지는 후속 작업이다.

## 목적과 범위

하루 목표를 물 마시기 행동 횟수로 표시한다. 카메라를 추가하기 전에는 사용자가 횟수를 직접 추가·취소한다. 텀블러를 다 비웠을 때 물뿌리개로 용량을 별도 기록하고 그 용량에 따라 식물이 성장한다. 텀블러 기록과 횟수 기록은 서로 추가하거나 환산하지 않는다.

## 처리와 이전 원칙

- 횟수 목표, 행동 기록, 텀블러 용량과 물 기록은 서로 구분한다. 한국 날짜 기준으로 집계하고 중복 요청과 오래된 화면을 검증한다.
- 기존 기록·목표·성장·설정과 조정 이력을 지우거나 가상의 행동 횟수로 변환하지 않는다. 기존 사용자에게 새 횟수 목표를 직접 설정하도록 안내한다.
- 스키마 변경 전 SQLite 백업을 만들고 실패하면 변경하지 않는다. 물 기록과 성장, 취소와 성장 취소는 같은 트랜잭션에서 처리한다.
- 하루 횟수 목표 달성은 습관 성취다. 성장량은 텀블러 기록의 용량에 비례하는 임시 기준을 적용하고 추후 사용하며 조정한다.
- 알림은 횟수 목표와 최근 유효 행동을 기준으로 한다. 기존 ml 데이터는 이전 이력으로 계속 조회할 수 있어야 한다.

## 검증

- 첫 실행·기존 사용자 이전·목표 중단과 재설정, 횟수 추가·취소, 물 기록·취소와 재시작 복원.
- 물 기록이 횟수를 늘리지 않고 횟수 기록이 ml·성장을 만들지 않는지 확인한다.
- 자정·중복 요청·오래된 목표·저장 오류·백업 실패·과거 성장 보존과 알림 조건을 검증한다.
- 빌드·린트·관련 테스트와 디자인 화면 확인을 수행한다. 실제 Mac 확인과 미완료 항목은 결과 문서에 남긴다.
