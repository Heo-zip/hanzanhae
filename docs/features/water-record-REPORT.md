# 물 한 잔 기록 결과

- 날짜: 2026-11-13 / 이슈: [#2](https://github.com/Heo-zip/hanzanhae/issues/2) / 브랜치: `feature/water-record`
- 계획: [물 기록 PLAN](water-record-PLAN.md) / 기반: 병합 전 [#1 PR](https://github.com/Heo-zip/hanzanhae/pull/3)

## 구현

- 정원 물뿌리개 또는 대시보드 버튼으로 현재 목표에 한 잔을 기록한다. 용량은 메인에서 저장된 설정을 읽으며 목표 없는 상태·오래된 목표/한국 날짜는 거절한다.
- DB 버전 3의 `water_records`에 요청 ID·목표·용량·UTC 시각·한국 날짜를 저장한다. 기존 버전 1·2 데이터와 총량 조정을 보존한다.
- 오늘 총량은 조정과 실제 물 기록을 합치며 잔 수에는 조정을 포함하지 않는다. 이전 목표의 오늘 기록도 유지한다. 날짜별 유효 기록을 최신순으로 표시한다.
- 중복 요청 ID는 한 번만 저장한다. 성공한 새 기록에만 두 창 갱신과 물뿌리개·물방울 연출을 알리고, 저장 실패에는 안내와 재시도를 제공한다.
- 이 보고서 작성 당시 생기·성장·취소·최근 7일 통계는 구현 전이었다. 이후 취소는 [취소 결과](water-cancel-REPORT.md)로 구현했으며 [생기·성장 계획](plant-growth-PLAN.md)과 [통계 계획](water-statistics-PLAN.md)도 이후 구현했다.

## 검증

- `npm run test:storage`: 11개 통과. 실제 용량·중복·이전 목표와 총량 조정·목표 중단·강제 저장 실패와 재시도·한국 자정·버전 1/2 이전·재실행을 확인했다.
- 별도 임시 데이터의 macOS 개발 Electron: 정원과 대시보드 기록, 연속 클릭 방지, 목표 달성·초과, 저장 실패 시 물주기 연출 차단과 재시도, 두 창 갱신·재실행, 제3의 창 쓰기 차단을 확인했다.
- 별도 임시 데이터의 macOS arm64 ad-hoc 패키지: 최초 설정, 물 기록, 정원 연출, 두 창 갱신과 재실행 복원을 확인했다.
- 타입 검사·린트·빌드 통과. [테스트 기대값 오류](water-record-test-contract-ERROR.md)는 수정했다.

## 남은 검토

- 물줄기의 위치와 크기, 정원 창에서의 사용감은 사용자 시각 검토가 필요하다. 원본 시안의 오른쪽 물뿌리개와 달리 이전 사용자 요청대로 왼쪽에 배치한다.
- 시스템 움직임 줄이기를 적용했지만 실제 macOS 접근성 설정의 수동 확인은 미실행이다.
- Developer ID 서명·공증·DMG 설치와 다른 Mac 칩은 미검증이다.
