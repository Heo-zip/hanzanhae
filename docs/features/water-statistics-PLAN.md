# 물 섭취 통계 PLAN

- 기능: 대시보드 물 섭취 통계 / 상태: 구현·자동 검증 완료, 사용자 QA 대기 / 우선순위: MVP
- 이슈: [#13](https://github.com/Heo-zip/hanzanhae/issues/13) / 브랜치: `feature/water-statistics`
- 기준: 로컬 `design/dashboard.html`, 기능·DB 명세.

## 범위와 기준

- 한국 날짜 기준 최근 7일 총량·각 날짜의 마지막 활성 목표, 물컵과 막대, 목표 달성·평균·최다 섭취일을 표시한다. 목표가 없는 날짜는 목표 없음으로 표시한다.
- 총량은 유효한 물 기록과 해당 날짜의 기섭취량 조정 합이다. 목표는 해당 날짜에 잠시라도 활성화됐던 목표 중 마지막으로 시작한 목표다. 전날부터 이어진 목표와 중단한 당일도 포함한다. 중단 다음 날부터 새 목표 전까지는 목표 없음이다.
- 평균과 달성 횟수는 최근 7일 중 목표가 있었던 날을 기준으로 한다. 목표가 없는 날은 분모와 달성에서 제외하며, 최다 섭취량이 0이면 최다일을 표시하지 않는다. 동률은 가장 최근 날짜를 표시한다.
- 연속 달성은 7일로 제한하지 않는다. 오늘 목표를 아직 달성하지 않았다면 어제부터 세며, 오늘 달성했다면 오늘을 포함한다. 과거 목표 없음·미달성은 연속을 끊는다. 목표 변경·기록 취소 후 원본 이력을 기준으로 다시 계산한다.
- 위 경계 규칙은 기존에 미정이던 부분의 첫 구현 기준으로 기록한다.

## 데이터와 연결

- 스키마를 추가하지 않고 목표의 시작·중단 시각과 물 기록·조정의 한국 날짜를 읽어 이력을 복원한다. 기록 삭제가 아닌 유효 기록만 합산한다.
- 대시보드에서만 조회 가능한 제한된 IPC를 추가한다. 저장 및 변경 알림을 재사용하고, 날짜 변경·오류 시 통계를 다시 읽는다. 정원에서 임의 SQL을 호출할 수 없다.
- 저장된 개인 기록을 로그와 문서에 노출하지 않는다.

## 검증

- 하루 목표 변경·중단/재개, 자정, 첫 설정 전 날짜, 취소·조정, 7일 밖 연속 달성, 빈 통계, 목표별 그래프를 확인한다.
- 실제 Electron에서 시안과 크기·상태를 비교하고 기록·취소·설정 변경 뒤 갱신과 오류 안내를 확인한다.
- 저장소 테스트, 타입 검사·린트·빌드와 실행 환경을 검사한 뒤 결과를 기록한다.
