# 알림 정책 분리 후 저장소 테스트 모듈 오류

- 상태: 수정·재검증 완료 / 관련: [알림 PLAN](plant-reminders-PLAN.md)

## 현상과 원인

알림 설정의 입력 검증을 별도 TypeScript 정책 파일로 분리한 뒤 `npm run test:storage`에서 해당 모듈을 찾지 못했다. 기존 테스트 도구가 저장소 파일만 임시 변환하고 그 파일이 가져오는 TypeScript 모듈은 변환하지 않았기 때문이다. 앱 빌드와는 별도의 테스트 로더 문제다.

## 수정

저장소 테스트에서 필요한 TypeScript 의존성도 동일한 변환 방식으로 불러오도록 보완하고, 이전 로더는 테스트 초기화 후 복구했다. 알림 설정 마이그레이션과 기존 버전 이전을 포함한 저장소 테스트를 다시 실행해 통과했다.
