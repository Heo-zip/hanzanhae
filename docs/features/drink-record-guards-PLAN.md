# 물 기록 중복 입력 확인

- 2026-11-22 · [#64](https://github.com/Heo-zip/hanzanhae/issues/64) · `feature/drink-record-guards`

## 동작

- 첫 두 번의 수동 추가는 바로 저장한다. 최근 3초 안에 이미 수동 기록이 두 번 있거나 카메라 기록이 하나라도 있으면 확인한다. 시간이 지나면 다음 입력은 바로 저장한다. 수치는 사용하며 조정한다.
- 확인창은 ‘방금 또 마셨나요?’와 확인 이유를 보여 준다. ‘돌아가기’와 Esc는 보류한 입력을 취소한다. ‘1회 추가’는 한 번만 저장한다. 모달을 기존 대시보드 `dialog.confirm` 스타일로 표시한다.
- 텀블러를 비우면 기록한 용량과 해당 기록의 되돌리기를 버튼 아래에 표시한다. 새 텀블러 기록이 생기거나 날짜·목표가 바뀌면 이전 안내에서 되돌릴 수 없다. 오늘 기록 목록의 기존 취소 흐름을 유지한다.

## 저장과 예외

- Main 프로세스는 저장된 최근 횟수로 확인 여부를 판단한다. 확인이 필요하면 쓰기 없이 확인 이유와 당시 최신 횟수 기록 ID를 돌려준다. 확인 요청은 최초 요청 ID·목표·한국 날짜를 사용하고 최신 기록 ID까지 검증한다.
- 다른 창이나 카메라가 기록을 바꿨거나 자정·목표가 바뀌면 저장을 거절한다. 응답 실패 재시도는 같은 ID로 처리하고 카메라 자동 추가에는 수동 확인을 적용하지 않는다.
- 텀블러 성공 응답에는 실제 저장한 레코드를 담아 누른 순간의 용량과 기록 ID로 안내한다. 되돌리기는 기존 `cancelWater(latest)`로 처리하며 더 최근 항목을 대신 취소하지 않는다.

## 검증

- 3초 경계, 첫 두 번과 세 번째, 카메라 직후, 확인 중 기록·목표·날짜 변경, 요청 재시도의 중복 방지를 저장소에서 검증한다.
- 정상 입력, 확인창 포커스·Esc·확인, 저장 재시도, 텀블러 용량과 정확한 되돌리기를 화면에서 확인한다.
