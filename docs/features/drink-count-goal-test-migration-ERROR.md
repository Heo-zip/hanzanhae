# 개발 중 오류 보고서: 횟수 목표 이전 테스트

## 기본 정보

- 기능: 횟수 목표와 텀블러 기록 분리
- 발생일: 2026-11-15
- 심각도: 낮음 / 상태: 해결
- 관련: [PLAN](drink-count-goal-PLAN.md), [Issue #34](https://github.com/Heo-zip/hanzanhae/issues/34)

## 환경과 재현

- macOS 26.6.1, arm64, Node.js 24.14.1, Electron 44.7.2.
- 기존 저장소 테스트에서 새 스키마로 만든 DB의 버전 번호만 낮춰 이전 버전인 것처럼 실행했다.
- 기대: 이전 DB를 새 스키마로 이전하고 기존 데이터를 보존한다.
- 실제: 횟수 목표 열이 이미 있어 스키마 이전 중 중복 열 오류가 발생했다. 일부 오래된 테스트는 ml 목표 기준의 기대값을 사용했다.

## 오류 메시지

```text
duplicate column name: target_count
```

## 원인과 해결

- 테스트 DB는 실제 이전 스키마와 달리 새 열과 테이블을 이미 포함했다. 버전 번호만 변경한 것이 원인이었다.
- 이전 버전 조건을 만드는 테스트에서 새 열과 테이블을 함께 제거하고, 새 목표·성장 정책에 맞게 기대값을 갱신했다.
- 새 테스트에 이전 백업, 기록·성장 보존, 목표 재설정, 중복 요청과 저장 실패 롤백을 추가했다.

## 검증과 후속 작업

- `npm run test:storage` 43개 통과. 알림·정원 위치·업데이트 관련 회귀 검사도 통과했다.
- 실제 사용자 DB는 사용하지 않았다. 서명된 패키지 버전 사이의 이전은 별도 확인한다.
