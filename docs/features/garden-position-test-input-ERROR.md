# 정원 드래그 검증 입력 오류

- 상태: 해결 / 관련 기능: [정원 위치 계획](garden-position-PLAN.md)

## 현상과 원인

Electron의 테스트용 마우스 입력으로 드래그했을 때 창이 움직이지 않았다. 테스트 입력에서 화면 좌표를 생략해 모든 포인터 이벤트의 `screenX`·`screenY`가 0으로 전달됐다. 숨기기 이벤트도 비동기여서 고정 시간만 기다린 검사가 간헐적으로 실패했다.

## 해결과 검증

마우스 입력에 전역 화면 좌표와 왼쪽 버튼 상태를 전달하고, 숨기기 후에는 목표 위치를 기다리도록 검증을 바꿨다. 실제 Electron 렌더러의 포인터 이벤트를 통해 클릭·드래그·취소·저장 실패·숨기기 복구를 확인했다. 물리 마우스와 실제 다중 모니터는 별도 사용자 QA가 필요하다.
