# 기능 결과 리포트: 횟수 목표와 텀블러 기록

## 기본 정보

- 기능: 하루 물 마시기 횟수 목표와 텀블러 용량 기록 분리
- 작성일: 2026-11-15
- 관련: [Issue #34](https://github.com/Heo-zip/hanzanhae/issues/34), [PLAN](drink-count-goal-PLAN.md), [이전 테스트 오류](drink-count-goal-test-migration-ERROR.md)
- 브랜치: `feature/drink-count-goal`. 사용자 요청에 따라 develop에 병합한다.

## 구현 결과

- 첫 설정과 설정 화면에서 목표 횟수와 텀블러 용량을 입력한다.
- 대시보드에서 횟수를 추가·최근 취소한다. 텀블러를 다 비우면 정원 물뿌리개 또는 대시보드에서 용량과 성장을 별도 기록한다.
- 두 기록 버튼을 같은 크기와 비중으로 나란히 배치하고 최근 횟수 취소를 그 위에 작은 보조 버튼으로 배치했다. 텀블러 버튼은 흰 배경에 초록 글자와 테두리를 적용했다.
- 설정 항목 제목을 조작 영역 위에 배치하고 반복 설명을 제거했다. 오늘 기록 목록의 내용과 스크롤바 사이에 여백을 뒀다.
- 통계와 알림은 횟수 목표를 기준으로 한다. 기존 ml 목표와 물 기록·성장은 유지하고 가상의 횟수로 바꾸지 않는다. 기존 사용자는 새 횟수 목표를 설정한다.
- 물 기록 시 용량 1ml당 1성장점의 임시 기준을 사용한다. 성장 속도와 임계값은 사용하면서 조정한다.
- 카메라 자동 인식은 구현하지 않았다. 인식률·오인식·개인정보와 카메라 권한은 별도 작업에서 검증한다.

## 변경 파일

| 영역 | 내용 |
| --- | --- |
| `src/shared`, `src/main/storage`, `src/preload` | 횟수·텀블러 데이터 모델, 스키마 이전, 검증, IPC와 중복 처리 방지 |
| `src/main/reminders` | 횟수 목표와 최근 행동 기준 알림 |
| `src/renderer/src/features` | 최초 설정, 오늘·설정·통계 화면과 정원 물 기록 |
| `tests` | 횟수·용량 분리와 이전 데이터 보존, 저장 실패, 자정·취소·알림 회귀 |
| `docs`, `AGENTS.md` | 최신 제품·저장·통신 규칙과 작업 이력 |

| 검증 | 결과와 제한 |

| `npm run build`, `npm run lint` | 통과. 타입 검사 포함 |

| 사용자 직접 QA | 미실행. 설정·목표 변경·정원·취소를 실제 사용 흐름으로 확인해야 한다. |
| 서명된 배포 앱 업데이트 | 미실행. Developer ID 서명 후 실제 버전 간 이전과 데이터 보존 확인 필요. |

환경: macOS 26.6.1, Apple Silicon arm64, Node.js 24.14.1, Electron 44.7.2. 테스트는 사용자 데이터와 분리한 임시 프로필에서 실행했다.

## 제한과 후속 작업

- 테스트 프로필에서 확인했으며 사용자 데이터로 직접 이전하지 않았다. 스키마 변경 전 앱은 로컬 백업을 생성한다.
- 자동 알림의 실제 시간 경과, 카메라 감지, 서명된 배포 앱의 업데이트는 별도 검증한다.
- 기록이 많은 화면의 스크롤과 실제 사용 환경에서의 동작은 추가 확인한다.
