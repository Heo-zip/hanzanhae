# macOS 바닥 위치 재실행 복원 오류

- 상태: 해결 / 관련 기능: [정원 위치 계획](garden-position-PLAN.md)

## 현상과 원인

화면 바닥에 저장한 화분을 재실행하거나 숨긴 뒤 다시 표시했을 때 원하는 좌표와 실제 창 좌표가 달랐다. macOS가 창 생성 시 작업 영역을 기준으로 창을 Dock 위로 보정했기 때문이다.

## 해결과 검증

처음 창을 표시한 직후 현재 저장 설정과 연결된 화면을 다시 확인해 좌표를 적용한다. 숨긴 창을 다시 표시할 때도 표시 전 좌표를 다시 적용한다. 설정이 그 사이 바뀐 경우 최신 값을 사용한다. 임시 데이터의 실제 Electron에서 화면 바닥과 항상 위 설정을 저장한 뒤 재실행하고 실제 창 좌표를 비교했다.
