# 최초 설정과 설정 화면 반영 PLAN

- 상태: 구현·개발 환경 검증 완료, 로컬 macOS arm64 패키지 첫 설정·복원 확인 / 브랜치: `feature/dashboard-ui` / 기준: `design/dashboard.html`, Issue #1
- 목적: 첫 실행을 시안의 4단계로 안내하고, 저장된 목표와 한 잔 용량을 설정에서 변경한다.
- 범위: 단계 이동과 입력 검증, 설정 저장·복원, 목표 중단과 새 목표 생성, 오늘 총량 조정. 물 기록과 성장 보상은 제외한다.
- 흐름: 최초 설정은 두 값을 확인 후 원자적으로 저장한다. 설정에서 목표를 바꾸면 기존 목표를 중단하고 새 목표를 생성하며 오늘 실제 총량과 입력 총량의 차이만 조정으로 보관한다. 목표 중단 후에도 설정에서 새 목표를 시작할 수 있다. 한 잔 용량 변경은 이후 기록에 적용한다.
- 데이터: 기존 DB를 버전 2로 이전하며 기존 목표·설정·식물을 보존한다. 한국 날짜별 총량 조정과 변경 요청의 중복 처리를 저장한다. 목표 변경 시 날짜·목표 상태가 달라졌다면 저장하지 않고 다시 확인한다.
- 연결: Renderer는 입력·실패를 표시하고 preload의 제한된 API를 호출한다. Main은 발신자·값·최신 상태를 확인하고 트랜잭션으로 저장·창에 변경을 알린다.
- 예외: 입력 오류, 저장 실패와 오래된 화면에서는 성공 표시 없이 값을 유지한다. 재시도와 중복 클릭을 처리한다.
- 검증: 스키마 이전, 변경·중단·재생성·날짜와 중복·실패 롤백·재실행, 타입 검사·린트·빌드 및 시안과 화면 비교. 패키지 충돌은 [오류 기록](initial-setup-packaged-qa-timeout-ERROR.md)에 원인과 해결을 기록한다.
