# macOS 배포와 앱 보안 보완 검증

- 2026-11-23 · `1.0.1` 배포 후보 · Apple Silicon Mac.

| 영역 | 확인 결과 |
| --- | --- |
| GitHub | `main`은 PR로만 변경하며 `v*` 배포 태그의 생성 주체를 제한했다. 태그 이동·삭제 방지, 소스 Secret Scanning·Push Protection, 배포 저장소의 신규 릴리스 수정 방지를 조회했다. 서명 환경은 태그 전용이며 환경 값 6개가 필요하다. |
| 앱 패키지 | Electron 44.11.5 빌드와 린트·타입 검사, 자동 테스트 122개가 통과했다. 서명한 앱에서 `GrantFileProtocolExtraPrivileges`가 꺼져 있음을 확인했다. |
| 화면과 카메라 | 분리한 프로필에서 앱 전용 주소로 대시보드와 정원을 열었다. 번들 CSS는 허용하고 앱 범위 밖 파일 요청은 거부했다. 가짜 카메라로 Worker 분석과 숨긴 대시보드에 전달되는 카메라 종료 이벤트를 확인했다. |
| 기록 | 초기화 도중 종료된 파일 상태를 재현해 다음 실행에서 이전 텀블러 기록이 복구되는 자동 테스트를 추가했다. |
| 설치 파일 | Developer ID로 앱과 DMG의 서명이 검증됐다. 생성된 업데이트 목록은 ZIP만 가리키며 실제 ZIP의 SHA-512와 일치한다. |
| 랜딩 | 로컬 Paperlogy 4종은 이전 CDN 파일과 바이트가 같다. 보안 헤더를 적용한 로컬 응답에서 FAQ·모달·복사·키보드 동작을 확인했다. 개인정보 안내 문구를 맞춘 뒤 1280×860, 375×812 시안 비교에서 다른 픽셀은 0개였다. |

로컬 Apple 공증 프로필이 401을 반환해 이번 후보의 공증 티켓과 실제 버전 간 업데이트는 확인하지 못했다. 환경 Secrets의 등록과 정식 배포 뒤 공개 DMG 설치, 실제 카메라·메뉴 막대 동작, 업데이트 후 기록 보존을 확인한다. [공증 오류 기록](release-security-notary-credentials-ERROR.md)
