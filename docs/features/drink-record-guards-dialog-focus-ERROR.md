# 횟수 추가 확인 후 포커스 복귀 실패

- 2026-11-22 · [#64](https://github.com/Heo-zip/hanzanhae/issues/64) · 수정·브라우저 재검증 완료.

## 현상과 원인

브라우저 자동 검증에서 Esc로 닫으면 수동 추가 버튼으로 돌아왔지만, ‘1회 추가’를 누르면 모달이 닫힌 뒤 포커스가 돌아오지 않았다. 저장 응답에서 React의 모달 상태를 먼저 비워, 열려 있던 `<dialog>`를 문서에서 직접 제거했다.

## 수정과 검증

응답 처리가 끝나면 모달이 `close()`를 호출하고, 실제 `close` 이벤트가 화면의 모달 상태를 정리한다. 초기 포커스는 ‘돌아가기’에 두고 브라우저가 원래 버튼으로 돌려보내도록 했다. 같은 브라우저에서 Esc와 확인 뒤 포커스 복귀를 모두 확인했다.
