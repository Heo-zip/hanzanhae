# 정원 위치와 창 설정 PLAN

- 기능: 정원 위치 이동·복원과 창 설정 / 상태: 구현·검증 완료 / 우선순위: MVP
- 이슈: [#15](https://github.com/Heo-zip/hanzanhae/issues/15) / 브랜치: `feature/garden-position`
- 기준: 로컬 `design/dashboard.html`, `design/garden.html`, 창·설정 명세.

## 목적과 범위

작업 중 화분을 원하는 위치로 옮기고 앱을 다시 열어도 유지한다. 위치가 화면 밖으로 나가면 연결된 화면의 보이는 위치로 복구한다. 설정의 Dock 위·화면 바닥 위치 선택과 다른 창 위에 표시 옵션을 연결한다. Dock 확대·자동 숨김 애니메이션 실시간 추적과 로그인 자동 실행은 제외한다.

## 동작

- 화분을 누르면 기존대로 물뿌리개가 열리고, 왼쪽 버튼을 누른 채 일정 거리 이상 움직이면 창을 드래그한다. 드래그 후 클릭으로 처리하지 않는다. 물뿌리개·되돌리기·우클릭·클릭 통과는 기존대로 유지한다.
- 직접 옮긴 위치는 드래그를 마칠 때 저장한다. 위치 선택에서 Dock 위를 누르면 해당 화면의 작업 영역 하단에, 화면 바닥을 누르면 해당 화면 하단에 둔다. 수평 위치는 유지한다. 이후 자유롭게 다시 끌면 두 위치 선택의 강조가 해제된다.
- 시작과 화면 변경 시 저장 위치가 화면에 완전히 들어가도록 조정한다. 여러 화면 중 겹치는 화면을 우선하고, 전부 사라졌다면 기본 화면으로 복구한다. 창이 숨겨져 있을 때 위치 복구가 다시 표시하지 않는다.
- 항상 위가 켜져 있으면 기존 `floating` 순서를 사용해 Dock보다 아래에 둔다. 꺼져 있으면 일반 창 순서로 동작한다. 설정 변경 실패는 안내하고 이전 화면 설정을 복구한다.

## 데이터와 연결

- SQLite 스키마 7의 독립 창 설정에 좌표·위치 기준·항상 위 여부를 저장한다. 최초 설정 전에도 위치를 복원하며 기존 설정·기록은 유지한다.
- Electron 메인이 화면 정보와 실제 창 위치를 관리한다. preload는 정원 드래그와 대시보드의 한정된 설정 함수만 노출한다. 발신 창·메인 프레임과 값을 검증한다.
- 끌기 중 저장하지 않고 종료할 때 저장한다. 저장 실패는 이전 위치로 되돌리고 정원에 오류를 표시한다.

## 검증

- 기존 버전 이전과 재실행, 좌표·옵션 저장, 저장 실패, 잘못된 입력과 다른 창의 호출 거절을 검사한다.
- 가상 화면 배열로 화면 밖·음수 좌표·화면 제거·Dock 위와 바닥 위치를 검증한다.
- 실제 Electron에서 클릭·드래그·물주기·숨기기, 설정 변경·재실행과 시안 비교를 확인한다. 실제 다중 모니터·Dock 동작은 가능한 환경과 남은 범위를 구분한다.
