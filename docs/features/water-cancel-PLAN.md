# 물 기록 취소 PLAN

- 기능: 최근 한 잔·오늘 현재 목표 기록 전체 취소 / 상태: 구현·검증 완료
- 관련 이슈: [#5](https://github.com/Heo-zip/hanzanhae/issues/5) / 브랜치: `feature/water-record-cancel`
- 기준: `design/dashboard.html`, `design/garden.html`, 제품·DB·IPC 명세.

## 목적과 범위

실수로 추가한 물 기록을 되돌린다. 오늘 현재 목표의 최근 유효 기록 한 잔 취소와 오늘 현재 목표 기록 전체 취소를 제공한다. 목표·다른 목표와 날짜의 기록·기섭취량 조정은 유지한다. 성장·생기는 아직 없으므로 계산을 만들지 않되 후속 구현에서 같은 트랜잭션에 연결한다.

## 사용자 흐름

1. 대시보드 오늘 기록에서 현재 목표의 최근 한 잔을 취소한다. 정원에서는 저장 직후 잠시 표시되는 되돌리기 아이콘으로 같은 작업을 할 수 있다.
2. 전체 취소는 현재 목표의 오늘 기록 건수와 양, 유지할 목표·다른 기록·조정을 확인한 후 진행한다.
3. 저장 성공 시 두 창의 총량·잔 수·기록을 갱신한다. 실패는 성공처럼 표시하지 않고 재시도할 수 있다.
4. 목표·한국 날짜·최근 기록 또는 전체 취소 대상이 확인 시점과 달라지면 요청을 거절하고 최신 상태를 확인한다. 취소 후 총량이 음수가 되면 거절하고 원인을 안내한다.

## 데이터와 연결

- 스키마 버전 4에서 취소 요청 결과를 보관한다. 기존 `water_records.cancelled_at`에 취소 시각을 남겨 이력과 요청 중복을 유지한다.
- 요청 ID·작업 종류·목표·한국 날짜·기대 대상 목록을 검증한다. 대상 기록 취소와 요청 결과를 하나의 트랜잭션으로 저장한다. 동일 요청 재전송은 중복 적용하지 않는다.
- Preload는 제한된 취소 API만 제공하며, 메인은 정원·대시보드의 메인 프레임, 입력과 현재 상태를 검증한다. 정원은 최근 한 잔만 요청할 수 있다.
- 사용자 데이터는 로컬에 두며 로그나 문서에 실제 기록을 적지 않는다.

## 검증

- 최신·전체 취소 범위, 다른 목표·날짜·조정 유지, 음수 차단, 중복 요청, 저장 실패 롤백, 오래된 화면·자정, 버전 3 이전과 재실행을 확인한다.
- 임시 데이터의 실제 Electron에서 양쪽 창의 버튼과 전체 취소 확인, 실패 안내·두 창 갱신·복원을 확인한다.
- 사용자 QA로 기본 취소 흐름을 확인했다. 수정한 모달은 시안과 같은 크기로 비교하고 실제 Electron에서 정상·음수 차단·실패·재시도를 확인했다.
