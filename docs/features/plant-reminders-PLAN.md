## 목적과 범위

물을 잊고 있을 때 식물이 macOS 시스템 알림으로 물 마실 계기를 만든다. 알림을 눌러도 물은 자동 기록하지 않는다. 앱이 완전히 종료된 상태의 알림, 카메라와 MediaPipe는 제외한다.

## 첫 구현 기준

아래 수치와 세부 동작은 실제 사용하며 조정할 임시 기준이다.

- 알림은 기본 꺼짐. 설정에서 사용 여부, 간격(1~8시간)과 시간대(한국 시간)를 선택한다. 기본 간격은 2시간, 시간대는 09:00~21:00이며 시작 포함·끝 미포함이다. 자정을 넘기는 시간대도 지원한다.
- 알림을 켜고 저장할 때 바로 확인 알림을 요청해 macOS 권한 요청을 유도한다. 설정은 저장됐지만 표시가 거부되면 화면에 별도로 안내한다. 확인 알림이 표시된 경우에는 자동 알림과 겹치지 않도록 그 시각부터 간격을 센다.
- 활성 목표가 있고 오늘 목표에 미달한 경우에만 검사한다. 마지막 유효 물 기록이나 현재 목표 시작 중 더 늦은 시각부터 설정한 간격이 지나야 하며, 이전 알림 이후에도 같은 간격이 지나야 한다. 기록이 없다면 목표 시작 시각부터 센다.
- 실행 중 1분마다 검사하고 잠자기에서 복귀하면 다시 검사한다. 앱이 완전히 꺼진 동안 예약하거나 알리지 않는다. 중복 처리를 방지하고 마지막 알림 시각은 실제 표시 이벤트 후 저장한다.
- 현재 식물 생기가 낮으면 시든 식물 문구, 그 외에는 가벼운 물 마시기 문구를 사용한다. 알림을 누르면 대시보드를 연다.
- 사용자가 macOS 알림을 허용하지 않거나 앱 서명·알림 표시가 실패해도 물 기록은 계속 사용할 수 있다. 표시 실패는 성공 시각으로 저장하지 않는다.
- 설정 화면은 기존 시안의 설정 행·토글 디자인을 활용한다. 변경은 저장 성공 후 반영하고 실패 시 오류를 안내한다.

## 데이터와 연결

- SQLite 마이그레이션으로 알림 사용 여부·간격·시작/종료 시각과 마지막 발송 시각을 추가한다. 기존 기록과 설정을 보존한다.
- Main이 저장소·시간·생기를 읽어 조건을 판정하고 Electron Notification을 생성한다. Renderer는 제한된 preload 함수를 통해 설정만 조회·변경한다. 권한·전송 실패와 창을 닫은 상태를 고려한다.
- 날짜와 시간대는 기존 서비스와 동일하게 Asia/Seoul을 사용한다. 모든 입력은 메인에서 검증하고 마지막 성공 시각은 재시작 뒤 중복 발송을 막는 데 사용한다.

## 검증

- 비활성·목표 없음·달성·첫 기록 전·기록 취소·자정 통과·시간대 밖·자정 넘김·재실행과 잘못된 설정을 확인한다.
- 저장 실패나 알림 실패가 물 기록을 바꾸지 않고 알림 성공으로 오인하지 않는지 확인한다.
- 저장소 마이그레이션, 알림 조건의 경계와 중복 방지, IPC 발신자·값 검증을 자동 검사한다.
- 실제 macOS에서 알림 허용·차단, 서명된 패키지의 표시와 클릭, Dock·메뉴·정원과의 공존을 가능한 범위에서 확인한다. 미실행 항목은 REPORT에 남긴다.
