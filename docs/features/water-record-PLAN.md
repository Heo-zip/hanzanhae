## 목적과 범위

사용자가 실제로 물을 마신 뒤 정원 물뿌리개 또는 대시보드에서 한 잔을 기록한다. 저장된 용량과 당시 목표·시각을 보관하고 한국 날짜 기준 오늘 총량, 잔 수, 기록 목록을 보여준다. 성공한 저장만 두 창에 반영하고 물주기 연출을 재생한다.

이 계획 당시 취소, 생기·성장 계산, 7일 통계와 달성 보상은 후속 작업이었다. 이후 취소는 [별도 계획](water-cancel-PLAN.md)으로 구현했다. 이후 [생기·성장 계획](plant-growth-PLAN.md)에서 사용하며 조정할 임시값을 적용했다. 기록 기능을 제공하더라도 미구현 상태를 화면에 정확히 안내한다.

## 사용자 흐름

1. 목표가 활성 상태라면 물뿌리개 또는 대시보드 버튼으로 기록한다. 목표가 없으면 비활성화한다.
2. 메인 프로세스는 현재 한국 날짜·목표를 확인하고 저장된 한 잔 용량을 이용해 기록한다. 중복 클릭·동일 요청 재전송은 한 번만 처리한다.
3. 저장 성공 시에만 두 창을 갱신하고 화분의 물뿌리기 연출을 보여준다. 실패하면 성공 연출 없이 재시도 안내한다.
4. 오늘 총량은 기존 목표의 기록과 기섭취량 조정을 포함하고, 잔 수는 실제 기록만 센다. 새 목표 생성 시 입력한 총량은 기존 총량을 중복하지 않는다.
5. 한국 날짜 변경 또는 목표 변경 후 오래된 요청은 거절하고 최신 상태를 확인한다. 앱 재실행 후 같은 기록을 복원한다.

## 데이터와 연결

- 기존 스키마를 버전 3으로 이전하고, 물 기록에 요청 ID·목표 ID·ml·UTC 시각·한국 날짜·취소 시각을 저장한다.
- 요청과 기록을 하나의 트랜잭션으로 처리한다. 같은 요청 ID의 같은 내용은 중복 적용하지 않고, 다른 내용은 거절한다.
- Preload는 범위가 제한된 기록 메서드와 기록 성공 이벤트만 노출한다. Main은 정원 또는 대시보드의 메인 프레임만 허용하고 목표·날짜를 다시 검증한다.
- 데이터는 로컬에만 보관한다. 로그와 문서에 실제 사용자 기록을 남기지 않는다.

## 검증

- 신규 및 기존 DB 이전, 첫 기록·초과 기록, 목표 없는 상태, 이전 목표 및 조정 합산, 날짜 경계와 stale 요청, 중복 요청·실패 롤백·재실행을 자동 검증한다.
- 임시 데이터로 실제 Mac 개발 앱에서 두 창의 버튼과 저장 성공·실패·애니메이션·복원을 확인한다. 패키지 검증 범위는 결과에 구분해 기록한다.
- UI는 같은 크기와 상태에서 시안과 비교하며, 작은 정원의 왼쪽 물뿌리개 방향을 유지하고 모션 축소 설정을 존중한다.
