# 목표 중단 화면 검증의 반환값 오류

- 기능: 설정 시안 반영 / 발생일: 2026-11-13 / 상태: 해결 / 심각도: 낮음
- 환경: macOS 개발 Electron, 별도 임시 데이터.

목표 중단 확인창을 자동 테스트하기 위해 `executeJavaScript`에서 확인 함수를 대체했다. 대입식의 결과로 함수 자체를 반환하면서 Electron이 직렬화할 수 없어 `An object could not be cloned` 오류가 발생했다. 제품 코드의 저장 오류가 아니라 테스트 스크립트의 반환값 오류다.

스크립트가 함수 대신 `undefined`를 반환하도록 수정했다. 재실행한 테스트에서 목표 중단, 화분 유지, 같은 총량을 유지한 새 목표 생성을 확인했다.
