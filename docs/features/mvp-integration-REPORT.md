# MVP 통합 검증 결과

- 이슈: [#27](https://github.com/Heo-zip/hanzanhae/issues/27)
- 환경: 2026-11-14, macOS 26.6.1 arm64, Electron 44.11.1, Node.js 24.14.1
- 기준: [통합 검증 계획](mvp-integration-PLAN.md)

## 확인 결과

| 항목                         | 결과        | 확인 내용                                                                                                                       |
| ---------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 저장소 통합 흐름             | 통과        | 최초 설정 → 물 기록 → 목표 달성·성장 → 최근 취소 → 재기록·전체 취소 → 통계·알림 기준 갱신 → 재실행 복원                         |
| 실제 Electron 대시보드       | 통과        | 별도 테스트 데이터에서 목표 500ml·한 잔 250ml 설정 후 두 잔 기록, 달성 상태와 그래프, 최근 한 잔 취소, 재기록 및 전체 취소 확인 |
| 실제 Electron 복원           | 통과        | 전체 취소 후 앱을 다시 열어 목표 500ml 유지와 섭취량 0ml 및 기록 없음 확인                                                      |
| 정원·대시보드 연동           | 통과        | 정원의 물뿌리개로 한 잔을 기록하고 대시보드·오늘 그래프의 250ml 반영 확인                                                       |
| 저장소·정원 위치·알림 테스트 | 통과        | 저장소 34개, 정원 위치 3개, 알림 12개 총 49개                                                                                   |
| 린트·타입 검사·빌드          | 통과        | `npm run lint`, `npm run build`                                                                                                 |
| 개발 앱 알림                 | 사용자 확인 | macOS의 한잔해 개발 알림을 켠 후 사용자가 알림이 정상 작동한다고 확인. 화면 공유 중 알림 표시 설정은 사용자가 직접 관리         |

실제 화면 검증은 별도 앱 식별자와 임시 데이터로 수행했다. UI 조작은 접근성 버튼을 이용했으며, 물리 마우스 이동과 모든 성장 단계의 애니메이션을 검증한 것은 아니다.

## 남은 확인

- 사용자 환경에서 정원 커서와 다른 앱의 클릭 통과·실제 드래그: [Issue #20](https://github.com/Heo-zip/hanzanhae/issues/20).
- 실제 설정 간격이 지난 뒤 자동 알림, 실제 다중 모니터·Dock 반응, Developer ID 서명·공증·DMG 설치.
- 생기 감소와 성장 수치는 임시 기준이므로 실제 사용하며 조정한다.
