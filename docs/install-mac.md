# 한잔해 설치 안내 (macOS)

> 지금 배포하는 한잔해는 Apple 개발자 서명과 공증을 받지 않았습니다. 앱 기능은 똑같이 동작하지만, 처음 열 때 macOS가 한 번 막습니다. 아래 순서대로 한 번만 허용하면 이후에는 그냥 열립니다.

## 준비물

- Apple Silicon(M1 이상) Mac. Intel Mac용 설치 파일은 아직 제공하지 않습니다.
- macOS 13 Ventura 이상 권장.

## 설치

1. 배포 페이지에서 `hanzanhae-mac-arm64.dmg`를 받습니다.
2. DMG를 열고 **한잔해** 아이콘을 **응용 프로그램(Applications)** 폴더로 끌어 놓습니다.
3. DMG 창을 닫고, Finder 사이드바에서 DMG를 꺼냅니다(⏏).

## 처음 열기 (한 번만)

1. 응용 프로그램 폴더에서 **한잔해**를 더블클릭합니다.
2. "한잔해을(를) 열 수 없습니다" 또는 "Apple이 악성 코드가 없음을 확인할 수 없습니다" 창이 뜨면 **완료**(또는 **확인**)를 누릅니다. **휴지통으로 이동**은 누르지 않습니다.
3. **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
4. 아래쪽 **보안** 항목에 "'한잔해'이(가) 차단되었습니다"가 보이면 **그래도 열기**를 누릅니다.
5. 암호(또는 Touch ID)를 입력하고, 다시 뜨는 창에서 **열기**를 누릅니다.

macOS 15 Sequoia부터는 앱을 우클릭해 '열기'로 여는 방법이 없어져 위 설정 화면을 거쳐야 합니다. '그래도 열기' 버튼은 앱을 한 번 열려고 시도한 뒤 약 1시간 동안 보입니다.

## 카메라 권한

카메라 감지를 처음 켜면 카메라 사용 허용 창이 뜹니다. **허용**을 누릅니다. 영상은 이 Mac에서만 처리하고 저장·전송하지 않습니다. 실수로 거부했다면 **시스템 설정 → 개인정보 보호 및 보안 → 카메라**에서 한잔해를 켭니다.

## 새 버전으로 업데이트

서명하지 않은 버전은 자동 업데이트를 지원하지 않습니다. 메뉴의 업데이트 확인을 누르면 직접 설치하라는 안내가 나옵니다.

1. 한잔해를 종료합니다(메뉴 막대 아이콘 → 종료).
2. 새 DMG를 받아 설치 2번처럼 응용 프로그램 폴더에 끌어 놓고 **대치**를 누릅니다.
3. 처음 열기 과정이 다시 필요할 수 있습니다.

물 기록·화분·설정은 앱이 아니라 사용자 데이터 폴더에 있어 앱을 바꿔도 그대로 유지됩니다. 업데이트 뒤 카메라 권한을 다시 물어볼 수 있습니다.

## 삭제

응용 프로그램 폴더에서 한잔해를 휴지통으로 옮깁니다. 기록까지 지우려면 앱 안의 **설정 → 기록 관리 → 모든 기록 지우기**를 먼저 실행합니다.
