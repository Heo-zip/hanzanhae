# 한잔해 설치 안내 (macOS)

공식 배포본의 앱에는 Developer ID 서명과 Apple 공증이 적용됩니다. [공식 릴리스](https://github.com/Heo-zip/hanzanhae-releases/releases)에서 설치 파일을 받습니다.

## 준비물

- Apple Silicon(M1 이상) Mac. Intel Mac용 설치 파일은 아직 제공하지 않습니다.
- macOS 13 Ventura 이상 권장.

## 설치

1. 배포 페이지에서 `hanzanhae-mac-arm64.dmg`를 받습니다.
2. DMG를 열고 **한잔해** 아이콘을 **응용 프로그램(Applications)** 폴더로 끌어 놓습니다.
3. DMG 창을 닫고, Finder 사이드바에서 DMG를 꺼냅니다(⏏).

## 처음 열기

응용 프로그램 폴더에서 **한잔해**를 더블클릭합니다. macOS가 손상되었거나 검증할 수 없다고 표시하면 실행을 중단하고 공식 릴리스에서 다시 받습니다.

## 카메라 권한

카메라 감지를 처음 켜면 카메라 사용 허용 창이 뜹니다. 사용할 때만 **허용**을 선택합니다. 영상은 이 Mac에서만 처리하고 저장·전송하지 않습니다. 대시보드를 닫아도 감지는 계속되며 메뉴 막대에서 끌 수 있습니다. 권한은 **시스템 설정 → 개인정보 보호 및 보안 → 카메라**에서 변경합니다.

## 새 버전으로 업데이트

메뉴 막대의 **업데이트 확인**에서 업데이트를 내려받고 재시작할 수 있습니다. 수동으로 교체하려면 아래 순서를 따릅니다.

1. 한잔해를 종료합니다(메뉴 막대 아이콘 → 종료).
2. 새 DMG를 받아 설치 2번처럼 응용 프로그램 폴더에 끌어 놓고 **대치**를 누릅니다.

물 기록·화분·설정은 앱이 아니라 사용자 데이터 폴더에 있어 앱을 바꿔도 그대로 유지됩니다. 업데이트 뒤 카메라 권한을 다시 물어볼 수 있습니다.

## 삭제

**설정 → 기록 관리 → 모든 기록 지우기**는 앱을 초기화하며 로컬 복구 사본을 남깁니다. 사본까지 지우려면 한잔해를 완전히 종료한 뒤 Finder의 **이동 → 폴더로 이동**에서 `~/Library/Application Support`를 열고 `hanzanhae` 폴더를 삭제합니다. 내보낸 CSV는 저장한 위치에서 따로 삭제합니다. 앱을 제거하려면 응용 프로그램 폴더의 한잔해도 휴지통으로 옮깁니다.
