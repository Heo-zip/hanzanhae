# 기능 명세

> 상태: [#34](https://github.com/Heo-zip/hanzanhae/issues/34)에서 횟수 목표와 텀블러 기록을 분리해 구현했다. 카메라 감지(#36·#47)도 연결했다.

UI는 로컬 `design/garden.html`과 `design/dashboard.html`을 기준으로 한다. `design/`은 Git에 포함되지 않아 새로 받은 저장소에는 없다. 시안의 데모 데이터와 미리보기 조작은 실제 제품 기능이 아니며, 기록·목표·성장 동작은 이 명세를 따른다.

## 최초 실행

1. 환영 → 하루 목표 횟수 → 텀블러 용량(ml) → 확인 순서로 진행한다. 목표와 용량은 사용자가 직접 양수 정수로 입력한다.
2. 설정을 건너뛸 수 없으며 목표·용량·식물 상태를 함께 저장한다. 실패하면 재시도할 수 있다.
3. 기존 ml 목표 사용자는 과거 기록을 유지한 채 새 횟수 목표를 설정해야 한다. 기존 물 기록을 행동 횟수로 환산하지 않는다.

## 정원과 창

- 작은 정원에서 식물을 누르면 물뿌리개가 나타난다. 활성 목표가 있을 때 텀블러를 비우고 물뿌리개를 누르면 용량이 기록된다. 저장 성공 후에만 물주기 연출이 나온다.
- 오늘 마신 횟수와 목표, 기록된 물의 양은 대시보드에서 확인한다.
- 처음에는 정원을 오른쪽 아래에 놓고 물뿌리개는 왼쪽 위로 펼친다. 화분을 클릭하면 물뿌리개를 열고 5px 이상 끌면 자유롭게 이동한다. 기본적으로 일반 앱 위·Dock 아래에 표시한다.
- 화분 우클릭 메뉴의 **정원 숨기기**로 숨긴다. **⌘ + ⌥ + ⇧ + H**는 정원 보이기·숨기기를 전환하며, 다른 앱이 단축키를 사용 중이면 메뉴 막대에 실패를 안내한다. 현재 단축키는 고정값이며 사용자 변경 기능은 아직 없다.
- 메뉴 막대에서 정원 보이기·숨기기, 대시보드 열기와 앱 종료를 제공한다. 단축키와 메뉴 막대의 정원 보이기는 작업 중인 앱의 입력 포커스를 가져오지 않는다.
- 창은 기본적으로 항상 위에 표시하며 설정에서 고정 여부를 변경할 수 있다. 설정의 Dock 위는 작업 영역 하단, 화면 바닥은 화면 하단에 놓는다. 프리셋 선택 시 수평 위치를 유지하고 직접 끌어 옮기면 프리셋 선택이 해제된다.
- 창을 닫으면 숨기고 메뉴 막대 또는 Dock 아이콘으로 다시 연다. 메뉴의 앱 종료는 앱을 완전히 종료한다.
- 저장한 창 위치가 연결된 화면 밖이면 보이는 위치로 복구한다.
- 로그인 시 자동 실행은 기본 꺼짐이며 설정에서 켠다. macOS·Windows 설치 앱에서만 바꿀 수 있고, 개발 실행에서는 바꿀 수 없다. macOS가 허용을 요구하면 시스템 설정 경로를 안내한다. Linux는 미지원으로 안내한다.
- 설정에서 텀블러 용량과 하루 목표 횟수를 변경하고 목표를 중단할 수 있다.

위치 저장·복원과 항상 위 설정은 구현했다. 로그인 시 자동 실행 설정을 구현했으며 패키징 앱의 실제 로그인 실행은 수동 확인한다. macOS 전체 화면 작업 공간에도 정원을 표시하도록 구성했으며 실제 전체 화면 앱과의 공존은 수동 검증한다.

Dock 반응은 향후 실험이다. Dock이 숨으면 화면 바닥, 나타나거나 확대되어 화분·물뿌리개와 겹치면 그 위로 이동하는 경험을 목표로 한다. 화분 조작 중에는 위치를 고정하고, Dock에서 벗어나면 여유를 두고 복귀한다. 사용자가 직접 숨긴 상태는 유지한다. 실제 Dock 영역의 안정적인 감지와 권한·배터리 영향을 확인한 뒤 도입 여부를 정하며, 현재는 작업 영역 변경에 대한 위치 보정만 제공한다.

## 운영체제별 지원

macOS를 기준으로 만들었고 Windows(NSIS 설치 파일)·Linux(AppImage·deb)용 빌드를 제공한다. Windows·Linux는 이 Mac에서 설치 파일을 만드는 데까지만 확인했고 실제 실행은 확인하지 않았다. 지원 여부 판단은 `src/shared/platform.ts` 한곳에 둔다.

| 기능                           | macOS                   | Windows                                 | Linux                                                      |
| ------------------------------ | ----------------------- | --------------------------------------- | ---------------------------------------------------------- |
| 로그인 시 자동 실행            | 지원(허용 필요 시 안내) | 지원                                    | 미지원 안내                                                |
| 자동 업데이트                  | 지원                    | 미지원 안내                             | 미지원 안내                                                |
| 정원 빈 곳 클릭 통과           | 지원                    | 지원                                    | 미지원 안내(정원 창 영역은 클릭을 받는다)                  |
| 화면 잠금 감지(생기 감소 속도) | 지원                    | 지원                                    | 미지원 안내(잠금 중에도 평소 속도)                         |
| 메뉴 막대·트레이               | 메뉴 막대 단색 아이콘   | 트레이 앱 아이콘, 왼쪽 클릭 시 대시보드 | 트레이 앱 아이콘(데스크톱 환경에 따라 보이지 않을 수 있음) |
| 시스템 알림                    | 지원                    | 지원                                    | 알림 서버에 따름                                           |

- 미지원 기능은 설정 화면의 위젯 동작·로그인 시 자동 실행 항목과 업데이트 확인 대화상자에 표시한다. 알림·카메라 권한 안내와 ‘Dock 위’ 문구(Windows·Linux는 ‘작업 표시줄 위’)는 OS에 맞춰 바꾼다.
- 트레이 아이콘이 보이지 않는 Linux 환경에서는 앱을 다시 실행하면 이미 실행 중인 앱이 대시보드를 연다.
- Windows·Linux는 기본 제목 표시줄을 쓰므로 macOS 창 버튼 자리를 비우지 않는다.

## 물 마시기 알림

- 설정에서 알림 사용 여부, 1~8시간 간격과 한국 시간의 시작·종료 시각을 선택한다. 기본은 꺼짐·2시간·09:00~21:00이다. 테스트 알림은 물 기록이나 발송 간격을 바꾸지 않는다.
- 시작·종료는 각각 시와 분을 선택하며 00:00~23:59의 1분 단위를 지원한다. 시간 선택은 현재 사용자 요청에 따라 로컬 `design/dashboard.html`의 기존 시스템 입력과 다르게 구현했다.
- 앱 실행 중 활성 목표가 있고 오늘 목표에 미달했을 때 목표 시작·마지막 유효 횟수 기록과 마지막 알림 후 정한 간격이 지나면 식물 생기에 맞춘 알림을 요청한다. 알림을 눌러도 물을 자동 기록하지 않는다.
- 앱이 완전히 종료된 동안은 알리지 않는다. 사용자가 알림 표시와 클릭을 확인했으며 간격 경과 후 자동 발송은 별도 확인한다. [알림 기록](features/plant-reminders-REPORT.md)을 따른다.

## 앱 업데이트

- 설치된 macOS 앱은 시작 30초 후와 6시간마다 새 버전을 확인한다. 메뉴 막대에서도 직접 확인할 수 있다. Windows·Linux는 자동 업데이트를 지원하지 않으며, 직접 확인하면 새 버전을 배포 페이지에서 받으라고 안내한다.
- 다운로드와 재시작은 각각 사용자가 선택한다. 거절한 버전은 앱 실행 중 자동으로 반복 질문하지 않으며 직접 확인하면 다시 볼 수 있다.
- 설치 전 생기 저장 확인에 실패하면 업데이트를 중단한다. 스키마 이전 전에는 로컬 데이터베이스를 백업한다. 서명된 실제 버전 간 업데이트와 데이터 보존은 아직 미검증이다.

## 대시보드 창

- 오늘·기록·설정 화면을 제공한다. 기본 크기는 1280×800, 최소는 1024×700이다. 너비 1180px 이하에서는 한 열로 바꾸고 창 높이에 맞춰 줄이지 않고 스크롤한다. 큰 화면에서는 내용 폭을 1,560px, 오늘 화분 카드 높이를 460px까지로 묶는다.
- 오늘 화면의 ‘물 마신 횟수 추가’와 ‘텀블러 비우기’는 같은 크기와 비중으로 나란히 배치한다. 최근 횟수 취소는 위쪽에 작은 보조 버튼으로 둔다. 횟수 추가는 초록 배경, 텀블러 비우기는 흰 배경에 초록 글자와 테두리를 사용한다.
- 최근 7일 행동 횟수와 목표, 기록한 물의 양, 달성·연속 기록을 제공한다. 기록 탭의 하루 평균과 가장 많이 마신 날은 마신 횟수 기준이다. 지난 ml 목표의 달성은 당시 ml 기준으로 유지한다.
- OS 화면 모드(밝게·어둡게)를 따라 색이 바뀐다. 바탕화면 위에 뜨는 정원은 밝은 색을 유지한다.
- 설정의 기록 관리에서 기록을 CSV로 내보내고, 모든 기록을 지워 첫 설정부터 다시 시작할 수 있다. 지우기 전에 확인 창을 띄우고 앱 데이터의 `backups` 폴더에 사본을 남긴다.
- 같은 날 목표를 바꾸면 마지막 목표와 그날의 횟수를 기준으로 판단한다. 목표가 없는 과거 날짜는 연속 달성을 끊으며 오늘 미달성이면 어제부터 계산한다.

## 목표와 물 기록

- 활성 목표가 있을 때 대시보드에서 물 마신 횟수를 수동으로 추가하거나 가장 최근 횟수를 취소한다. 물의 양은 바뀌지 않고, 생기를 올린 횟수는 성장점 250점을 더한다(취소하면 함께 빠진다).
- 텀블러를 다 비우면 정원의 물뿌리개나 대시보드에서 기록한다. 당시 설정된 용량을 오늘 총량에 더하고 식물의 생기와 성장을 반영한다. 횟수는 바뀌지 않는다.
- 대시보드의 오늘 기록 목록은 마신 횟수와 텀블러 기록을 최신 순으로 함께 보여 주고, 각 종류의 최근 기록 옆에 취소 버튼을 둔다.
- 전체 취소는 오늘 마신 횟수와 오늘 현재 목표의 텀블러 기록, 그에 연결된 생기·성장을 함께 취소한다. 텀블러 기록 없이 횟수만 있어도 전체 취소할 수 있다. 목표, 과거 또는 다른 목표의 기록, 예전 기섭취량 조정은 유지한다.
- 날짜는 한국 시간 00:00을 기준으로 바뀐다. 중복 요청과 오래된 날짜·목표·취소 대상을 검증하며 저장 성공 뒤에만 연출한다.
- 목표 변경이나 중단은 과거 기록과 성장을 유지한다. 이전 버전에서 남긴 기섭취량 조정은 그대로 총량에 포함한다.

## 식물 반응과 성장

- 마신 횟수와 텀블러 기록이 모두 생기와 성장을 올린다. 생기는 지금 얼마나 싱싱한지(시간이 지나면 줄어든다), 성장점은 얼마나 자랐는지(줄지 않는다)다. 하루 횟수 목표 달성 자체가 물의 양이나 성장을 만들지는 않는다.
- 임시 성장 기준은 텀블러 1ml당 1점(한 기록당 최대 1,000,000점), 마신 횟수 1회당 250점이다. 버튼은 5분 안에 다시 눌러 생기가 오르지 않은 횟수는 성장에도 넣지 않는다. 카메라 감지는 매번 넣는다. 대시보드 화분 카드는 다음 단계까지 자란 정도를 퍼센트와 막대로 보여 준다(다음 단계로 바뀌기 전까지 최대 99%). 정원 위젯에는 숫자를 띄우지 않는다. 단계는 0·3,000·7,000·14,000점이며 수치는 사용하며 조정한다.
- 생기 기준(결정 020): 새 사용자는 60에서 시작하고 범위는 20~100이다. 사용 중 시간당 -10, 화면 잠금·잠자기·앱 종료 중 시간당 -2. 마신 횟수 +6(카메라 감지는 제한 없음, 버튼은 마지막으로 생기를 올린 버튼 기록 뒤 5분이 지나야), 텀블러 +15(기록 순간 카메라 감지가 꺼져 있으면 +30).
- 기록마다 실제로 오른 생기를 저장하고, 횟수·텀블러 기록을 취소하면 그만큼 되돌린다. 1분 저장 주기보다 긴 공백은 잠자기·강제 종료로 보고 처음 3분만 사용 중으로 계산한다.
- 식물 사진은 생기에 따라 5장(90~100·70~89·50~69·30~49·20~29)으로 나뉜다. 20 폭 구간의 아래쪽 10에서는 색을 조금 더 바래게 한다. 성장 단계 4개 × 생기 5단계의 사진 20장은 같은 화분 위치로 만들었다(`assets/plants/`). 첫 설정 화면의 장식 화분은 기존 사진을 쓴다.
- 카메라 감지 기록은 정원에 물방울 연출과 감지 표시·되돌리기 버튼을 8초 보여 준다. 정원에서는 15초 안의 최신 카메라 기록만 되돌릴 수 있다.
- 기존 물 기록은 새 성장량으로 소급하지 않는다. 카메라 감지는 후속 실험으로, 영상 처리·정확도와 권한을 검증해야 한다.
